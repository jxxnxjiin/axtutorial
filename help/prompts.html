오늘 내가 친 문장¶

이 페이지가 하는 일

  • 여러분이 오늘 직접 친 문장을 여기에 옮겨 적습니다
  • 강사가 채워주지 않습니다. 완성 문장 창고가 아닙니다

집에 가져가는 물건은 이 페이지입니다. 내일 처음 보는 일 앞에서 열 페이지니까요.

옮겨 적는 법¶

각 실습을 끝낼 때마다, Claude Code 화면을 위로 올려 여러분이 친 문장을 찾아 여기에 옮겨 적으세요. 종이에 적어도 되고, 이 페이지를 복사해 메모장에 붙여넣고 채워도 됩니다.

AI가 답한 것은 적지 않습니다. 여러분이 친 것만 적습니다.
