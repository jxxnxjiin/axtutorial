화면과 도구¶

말 한 줄 풀이
VS Code 오늘 실습을 진행하는 작업 프로그램. 왼쪽에는 파일 목록, 오른쪽에는 AI 대화창이 뜹니다
에디터 파일 내용을 열어 보고 고치는 화면입니다. VS Code가 대표적인 에디터입니다
터미널 명령어를 글자로 입력하는 화면입니다. VS Code 아래쪽이나 PowerShell 창에 열립니다
PowerShell Windows에 기본으로 들어 있는 터미널 프로그램입니다
명령어 컴퓨터에게 글자로 내리는 지시입니다. 예: python --version
CLI 버튼을 누르는 대신 명령어로 쓰는 프로그램입니다. "터미널에서 쓰는 도구"라고 생각하면 됩니다
패널 VS Code 안에서 옆이나 아래에 붙어 열리는 작은 작업창입니다
확장 VS Code에 기능을 더하는 추가 프로그램입니다. Claude Code도 확장으로 붙여 씁니다
설정 도구가 어떻게 동작할지 정해두는 메뉴나 파일입니다
모드 도구의 동작 방식을 고르는 상태입니다. 예를 들어 자동으로 진행할지, 매번 물어볼지 정합니다

AI에게 시킬 때¶

말 한 줄 풀이
AI 코딩 에이전트 말로 시키면 파일을 읽고, 만들고, 고치는 AI 도구입니다
Claude Code 이번 자료에서 쓰는 AI 코딩 에이전트 이름입니다
프롬프트 AI에게 보내는 지시문입니다. "무엇을, 어떻게, 어떤 파일로"를 적습니다
스킬 자주 쓰는 작업 절차를 이름 붙여 저장해 둔 것입니다. 다음부터는 다시 설명하지 않고 불러 쓸 수 있습니다
슬래시 커맨드 /스킬이름처럼 /로 시작하는 호출 문장입니다
모델 AI의 두뇌 종류입니다. 같은 질문도 어떤 모델을 쓰느냐에 따라 속도나 답이 달라질 수 있습니다
API 키 AI 같은 외부 서비스를 쓸 때 필요한 비밀 열쇠입니다. 다른 사람에게 보여주거나 공개 파일에 올리면 안 됩니다

파일 이름에서 자주 보이는 말¶

말 한 줄 풀이
경로 파일이나 폴더가 컴퓨터 안 어디에 있는지 나타내는 주소입니다. 예: lab7/2.견적통합/견적비교표.xlsx
.claude 폴더 Claude Code가 설정과 스킬을 저장해 두는 숨은 폴더입니다
SKILL.md 스킬의 설명과 작업 절차가 적힌 파일입니다
CLAUDE.md 이 폴더에서 AI가 지켜야 할 규칙을 적어두는 파일입니다
AGENTS.md 프로젝트에서 AI 에이전트가 참고할 작업 규칙을 적어두는 파일입니다
.env API 키처럼 밖에 공개하면 안 되는 값을 넣어두는 설정 파일입니다

웹과 공유¶

말 한 줄 풀이
브라우저 인터넷 화면이나 HTML 파일을 여는 프로그램입니다. 크롬, 엣지, 사파리 같은 것들입니다
GitHub 코드, 스킬, 예제 파일을 올려두고 공유하는 웹사이트입니다
저장소 GitHub에서 하나의 프로젝트가 담긴 공간입니다. 영어로 repository라고도 부릅니다
Raw GitHub에서 파일의 꾸밈 없는 원문만 여는 버튼입니다. SKILL.md를 복사할 때 씁니다
HTML 브라우저에서 열리는 화면 파일입니다. 더블클릭하면 웹페이지처럼 볼 수 있습니다
서버 브라우저가 요청하면 결과를 만들어 돌려주는 프로그램입니다. 웹앱은 보통 서버와 화면이 같이 움직입니다

문서와 데이터 파일¶

말 한 줄 풀이
CSV 쉼표로 칸을 나눈 표 파일입니다. 엑셀로도 열 수 있습니다
md 파일 마크다운 문서 파일입니다. 글자만 담는 가벼운 문서라 규칙, 보고서, 스킬 설명에 자주 씁니다
마크다운 문서를 간단한 기호로 꾸미는 방식입니다. #은 제목, -는 목록입니다
JSON 프로그램이 읽기 쉬운 구조로 값을 적어둔 파일 형식입니다. 설정이나 원본 데이터 저장에 자주 씁니다
