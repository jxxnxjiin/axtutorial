에러가 났어요¶

이 페이지가 하는 일

  • 빨간 글씨가 떴을 때 그대로 복사해 쓸 문장을 모아뒀습니다
  • 증상별로 어떤 문장을 보낼지 표로 정리했습니다

빨간 글씨는 정상입니다. 직접 해석하려고 애쓰지 마세요. 있는 그대로 전달하는 것이 핵심입니다.

먼저 붙일 한 줄¶

에러를 그대로 붙여넣기만 하면 상황을 몰라 여러 번 오갑니다. 아래 한 줄을 같이 보내면 왕복이 절반으로 줍니다.

짐작 한 줄

지금 (어느 단계)에서 (어떤 파일)을 (어떻게) 했더니 났어. 내 짐작엔 (          ) 때문인 것 같아.

짐작이 틀려도 됩니다. 틀린 짐작도 단서입니다. 어디서 무엇을 했는지가 들어 있는 것만으로 충분합니다.

여유가 없으면 아래 문장만 써도 됩니다. 막힌 상태로 멈춰 있는 것보다 낫습니다.

이런 에러가 났어:
(에러 메시지를 그대로 복사해서 붙여넣기)

원인이 뭔지 설명해주고 해결해줘.

증상별로 그대로 쓸 문장¶

파일이 안 보이거나 못 찾을 때¶

증상 그대로 복사할 문장
만들었다는 파일이 폴더에 없다 결과가 어디에 저장됐는지 전체 경로로 알려줘.
파일을 못 찾는다고 한다 지금 폴더에 어떤 파일이 있는지 목록으로 보여줘.
열려 있는 폴더가 맞는지 모르겠다 지금 열려 있는 폴더 경로가 어디야?
파일 이름이 내가 정한 것과 다르다 이 파일 이름을 (내가 정한 이름)으로 바꿔줘. 안에 있는 내용은 그대로 둬.

숫자나 행 수가 이상할 때¶

증상 그대로 복사할 문장
행 수가 예상과 다르다 지금 표가 몇 행인지 세서 알려주고, 어떤 파일에서 몇 행씩 가져왔는지 파일별로 알려줘.
숫자가 어디서 왔는지 모르겠다 이 숫자를 어느 파일 어느 시트 몇 번째 행에서 가져왔는지 알려줘.
"일치합니다"만 답한다 말로 말고 숫자로 보여줘. 왼쪽=얼마, 오른쪽=얼마.
빠진 게 있는 것 같다 원본과 결과를 대조해서 빠진 행만 목록으로 알려줘.

고쳤더니 다른 게 망가졌을 때¶

증상 그대로 복사할 문장
전체가 다시 만들어졌다 방금 변경을 되돌려줘.
고치라고 한 것 말고도 바뀌었다 방금 바뀐 것 중에 내가 고치라고 한 것과 관계없는 변경이 있으면 되돌려줘.
한 곳만 고치고 싶다 (그 부분)만 고치고 나머지는 건드리지 마. 고친 뒤에 뭘 바꿨는지 알려줘.
원본 파일이 바뀌었다 원본 파일을 이전 상태로 되돌리고, 결과는 새 파일에 써줘.

화면(실습 4)에서¶

증상 그대로 복사할 문장
화면이 안 열린다 화면이 안 열려. 지금 뭘 해야 볼 수 있는지 순서대로 알려줘.
빈 화면이 뜬다 화면은 열리는데 아무것도 안 보여. 표가 몇 행 들어가 있는지 먼저 알려줘.
글자가 깨진다 글자가 깨져서 나와.
한 번에 너무 많이 한다 한 번에 다 하지 말고, 지금은 표만 보이게 해줘.

환경 문제¶

증상 원인 대응
command not found / 명령을 찾을 수 없습니다 설치 후 터미널을 다시 안 열었다 VS Code를 완전히 껐다 켜세요
터미널 경로가 이상하다 파일 열기를 했다 파일 > 폴더 열기 로 다시 여세요
파일 수정마다 확인 창이 뜬다 자동 승인이 안 켜졌다 ④ AI 에이전트 설치 3번
한글 파일 이름이 깨진다 압축 프로그램 문제 다른 압축 프로그램으로 다시 푸세요
로그인 화면에서 막힌다 계정 문제 조교를 부르세요. 예비 계정이 있습니다
답이 3분 넘게 없다 멈춘 상태일 수 있다 Ctrl+C 로 멈추고 다시 시도하세요

그래도 안 되면¶

각 실습 폴더의 못따라왔을때/ 를 여세요. 그 단계까지의 결과가 완성된 채로 들어 있습니다.

여는 데 이유를 대지 않아도 됩니다. 오늘은 완주가 먼저입니다.
