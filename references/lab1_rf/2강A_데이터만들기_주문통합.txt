2강-A · 데이터 만들기 — 흩어진 주문 파일 통합
(원본: 온라인 강의 교안 「3. 강사 대본 / 멘트」 · 2강 전반부)
대응 실습: lab1 (흩어진 주문 한 표로 모으기)
사용 자료: materials/2강/1. Order/ (웹주문·전화주문·제휴주문·주문종합·작업방법참고)

────────────────────────────────────────
[00:00–01:30] 인트로 — "오늘의 강의는 데이터 만들기"
────────────────────────────────────────

"오늘 해볼 작업은 ①번 데이터 만들기예요. 각각 취합된 데이터(이미 표로 된 것) 여러
개를 → 종합파일 한 개로 합치는 작업과 유형이 정해져 있지 않은 문서들에서 데이터를
뽑아 정리하는 작업을 해볼 겁니다."

"먼저 여러개의 파일에 흩어져 있는 데이터를 합쳐서 하나로 만드는 작업을
해보겠습니다. 화면을 보시면. 폴더 안에 주문 파일이 세 개 있어요. 웹주문, 전화주문,
제휴주문. 같은 회사 주문인데, 주문받은 통로가 달라서 파일 내용이 조금씩 다릅니다.

(화면전환 후)
열 이름도 제각각이고 데이터 양식도 조금씩 다른데 이걸 한 표로 합치라는 게 주어진
업무라고 해보죠. 지금은 짧은시간에 보여드리기 위해서 많지 않은 데이터로
보여드리지만, 실제로는 수만 건이면 작업이 몇시간 걸립니다. 오늘은 이걸 AI한테
맡겨서 작업하도록 해볼겁니다."

────────────────────────────────────────
[01:30–03:00] 데이터 살펴보기 + 함정(문제점) 찾기
────────────────────────────────────────

"보세요. 웹주문은 첫 칸이 '주문번호'. 전화주문은 같은 자리가 'order_id'. 제휴주문은
'협력사주문ID'. 셋 다 같은 뜻이에요. 사람은 눈으로 보면서 쉽게 인식이 되지만 AI는
그렇지 못할수도 있어요. 이걸 AI한테 규칙으로 넘기는 게 오늘의 핵심입니다."

  표준 칸    | 웹주문     | 전화주문   | 제휴주문
  주문번호   | 주문번호   | order_id   | 협력사주문ID
  고객명     | 고객명     | name       | 구매자
  상품명     | 상품       | item       | 품목
  수량       | 수량       | qty        | 개수
  매출액     | 금액       | amount     | 결제액
  주문일자   | 주문일시   | date       | 일자

"그리고 함정이 더 있어요. 날짜가 파일마다 달라요 — 웹은 '2026-01-06 14:30'처럼
시각까지 붙어 있고, 전화는 '2026/01/06', 제휴는 '01/06/2026'. 금액도 웹은
'"1,200,000"' 콤마 붙은 글자, 나머지는 그냥 숫자. 또 같은 주문이 두세 채널에 동시에
잡혀서, 똑같은 주문이 여러 파일에 들어 있기도 해요."

"데이터를 종합하는 작업은 다음 세가지를 지키면서 해야해요.
빠뜨리지 않는다. 맘대로 바꾸지 않는다. 없는 건 지어내지 않는다."

────────────────────────────────────────
[03:00–07:30] 작업 시연 ① — 여러 파일의 데이터 종합하여 만들기
────────────────────────────────────────
(화면: 파일 탐색기에서 작업 폴더를 연다. 웹주문·전화주문·제휴주문(원본 3개) +
주문종합(제출 양식) + 작업방법참고(작업지침) 다섯 파일을 보여준다.)

(작업방법 참고 파일 열고)
"그럼 이제 AI에게 일을 시킬 규칙을 정해주는거에요. 제가 정리놨는데 같이 보면서
어떻게 정했는지 살펴보죠. (내용을 읽으며 설명한다)"
"이제 AI 에이전트에게 일을 시켜보죠."

단계 1 — 폴더째 맡기고 규칙부터 읽히기. 첫 프롬프트:

  "data 폴더에 주문 파일 세 개(웹주문, 전화주문, 제휴주문)랑 주문을 종합할 양식
  주문종합 파일이 있어, 먼저 작업방법참고 파일의 '작업방법' 시트를 읽고, 각 칸
  이름·형식이랑 합치는 규칙을 나한테 요약해서 말해봐. 아직 데이터를 종합하지는 마."

→ 화면에 떠야 할 것: AI가 안내 시트를 읽고 "표준 7칸(주문번호·고객명·상품명·수량·
금액_원·주문일·출처채널), 같은 주문번호는 한 줄로, 날짜는 YYYY-MM-DD로, 금액은
콤마 빼고 숫자로, 빈칸은 비워둠" 같은 규칙을 자기 말로 정리해서 보여준다.

"보면 AI가 작업방법을 읽고 자기 나름대로 정리해서 브리핑을 하죠? 그걸 잘 읽어보고
뭐 빠진게 있으면 추가하고 문제없겠다 싶으면 이제 작업을 지시하면 됩니다."

단계 2 — 합치기 지시. 두 번째 프롬프트:

  "이제 세 파일의 데이터를 작업방법대로 합쳐서 주문종합 파일에 채워줘."

단계 3 — 결과 열어 눈으로 확인. 주문종합 파일을 연다. 주문번호가 한 번씩만
나오는지, 주문채널이 잘 작성되어 있는지 확인한다.

"작업이 완료되었으면, 주문종합 파일을 열어서 중복주문이 잘 처리되었는지 각 열의
내용은 잘 정리되었는지 확인합니다."

단계 4 — 검산 시키기(가장 중요). 세 번째 프롬프트:

  "검산해줘. 원본 세 파일의 주문 줄 수를 각각 세고 다 더해줘. 그중 같은 주문번호가
  여러 파일에 겹친 건이 몇 건인지, 그래서 중복을 접으면 통합표가 몇 줄이어야 맞는지
  계산해줘. 그 숫자가 방금 만든 통합주문 시트 줄 수랑 같은지 확인해줘. 다르면 빠진
  주문번호를 찾아서 알려줘."

→ 화면에 떠야 할 것: "원본 합계 432줄, 그중 중복을 접으면 252건, 통합표도 252줄 →
일치"처럼 숫자로 증명하는 보고. (값은 데모 데이터 기준이며, 강사는 실제로 나온
수치를 읽어주면 된다.)

"AI가 작업을 마쳤다고 무조건 믿지 마세요. 여러가지 방법으로 해당 작업이 완벽하게
되었는지 확인해 보는게 꼭 필요합니다. 여기서는 데이터의 수를 세어보게 시키는 것으로
했지만 검사를 할 방법은 작업에 따라서 달라질 겁니다."

────────────────────────────────────────
[07:30–08:00] 여러 업무 적용가능
────────────────────────────────────────

"지금 우리는 '주문'을 합쳤지만, 실제로는 여러 데이터를 작업하게 될거에요. 지점별
매출을 모아서 한 표로 합치기, 채널별 고객 문의를 한 시트로 모으기, 거래처별
견적서를 비교표로 합치기 등은 전부 데이터 종합이에요. 종합하는 대상에 차이가 있을
뿐, 시키는 방법은 비슷합니다."
