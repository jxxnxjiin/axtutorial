# references — 온라인 강의 교안(강사 대본) 레퍼런스

위키 실습(lab) 페이지에 살을 붙일 때 참고할 원본 강의 대본입니다.
강 번호와 lab 번호가 1:1이 아니므로 아래 매핑을 기준으로 정리했습니다.

| 폴더 | 원본 강 | 대응 실습 |
|---|---|---|
| `intro_rf/` | 1강 (인트로·6유형·컨텍스트 엔지니어링·업무지시 3요소) | lab 없음 — types/여섯 가지 업무 유형, 홈 "오늘의 지도" |
| `lab1_rf/` | 2강 전반부 (주문 파일 통합) | 실습 1 · 흩어진 주문 한 표로 모으기 |
| `lab2_rf/` | 2강 후반부 (계약서 PDF 뽑기) + 2강 마무리 | 실습 2 · 계약서에서 계약종합 만들기 |
| `lab3_rf/` | 3강 (자료 요약·집계) + 5강 (분석하기·인사이트) | 실습 3 · 쿠폰 성과 집계·인사이트 (두 강이 병합됨) |
| `lab4_rf/` | 6강 (보고자료 만들기) | 실습 4 · 임원용 1페이지 보고서 |
| `lab5_rf/` | 4강 (딱지 붙이기) | 실습 5 · 고객 문의 520건에 딱지 붙이기 |
| `lab6_rf/` | 7강 (확인하고 수정하기) | 실습 6 · 제안서 내용 검증하기 |
| `lab7_rf/` | 8강 (확장과 재사용·스킬화) | 실습 7 · 반복작업을 재사용 스킬로 만들기 |

주의: 대본은 강의 방영 순서(4강 분류 → 6강 보고서) 기준이라, 현재 위키의 실습
순서(실습 4 보고서 → 실습 5 분류)와 순서가 다릅니다. 대본 속 "다음 강에서는 ~"
멘트도 방영 순서 기준입니다.
