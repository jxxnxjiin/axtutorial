# 2단계. 청구서 두 장을 하나로 합치기

!!! abstract "이 단계에서 하는 일 (약 13분)"
    - 서식이 다른 청구서 두 장을 하나의 표로 합칩니다
    - 우리 발송 기록과 짝을 맞춰봅니다
    - 짝이 안 맞는 건을 지우지 않고 표시로 남깁니다

두 회사가 보낸 청구서는 칸 이름부터 다릅니다. 한쪽은 `송장번호`, 한쪽은 `운송장`입니다. 금액을 적는 방식도 다릅니다.

??? question "① 4분이 지나도 막혔다면 — 아직 펼치지 마세요"
    지금 표에 **발송내역 120건**은 들어 있나요?

    > 펼치기 전에 한 번만 더 시도해보세요.

??? tip "② 9분이 지났다면 — 정해야 할 세 가지"
    정해야 할 것은 셋입니다 — **입력이 몇 개인지 / 한쪽에만 있는 건을 어떻게 할지 / 원본을 어떻게 할지.**

    **정답 행 수는 122행입니다.** 왜 122인지는 여러분이 채우세요.

    이 단계 결과는 `물류비_점검표.xlsx` 의 `건별판정` 시트에 들어갑니다.

??? example "③ 모범답안 — 잘 되는 문장은 이렇게 생겼습니다 (여러분 문장을 한 번 보내본 뒤에 여세요)"

    ```
    발송내역.xlsx, 청구서_A택배.csv, 청구서_B물류.xlsx 세 개를 다 읽어서 하나의 표로 합쳐줘.
    원본 세 개는 고치지 말고 읽기만 해.
    결과는 물류비_점검표.xlsx 파일의 건별판정 시트에 새로 만들어줘.
    발송내역에 없는 송장은 발송기록없음, 청구서에 없는 발송건은 미청구라고 남겨줘.
    금액은 숫자만 쓰고, 부가세가 포함된 금액인지 아닌지는 따로 칸을 만들어 적어줘.
    다 되면 최종 행수가 몇 행인지 알려줘.
    ```

    **이 문장이 하는 일**

    | 이 줄이 | 없으면 |
    |---|---|
    | `발송내역.xlsx, 청구서_A택배.csv, 청구서_B물류.xlsx 세 개를 다` | 청구서 두 개만 합쳐 118행이 나옵니다. 우리 기록에 있는 120건과 맞춰볼 수가 없습니다 |
    | `원본 세 개는 고치지 말고 읽기만 해` | 받은 청구서 파일이 정리되면서 바뀝니다. 되돌릴 방법이 없습니다 |
    | `발송기록없음 / 미청구라고 남겨줘` | 짝이 안 맞는 6건이 조용히 사라집니다. **사라진 건은 세어볼 수도 없습니다** |
    | `최종 행수가 몇 행인지 알려줘` | "합쳤습니다"로 끝납니다. 122인지 118인지 직접 세야 합니다 |

    **한 번에 잘 됐다면** — 여러분 문장과 이 답안에서 **다른 곳을 한 곳만** 찾아보세요. 답안이 더 나은 곳도, 여러분 문장이 더 나은 곳도 있습니다. 둘 다 있는 게 정상입니다.
    **아직 어긋난다면** — 이 문장으로 갈아타고 다음 단계로 가세요. **오늘은 완주가 먼저입니다.** 갈아탔다고 뒤처진 게 아닙니다.

## 뭐가 달라졌는지 봅니다

!!! success "이렇게 나오면 정상입니다"
    - `물류비_점검표.xlsx` 에 `건별판정` 시트가 생겼습니다
    - 행 수가 **122행**입니다
    - 청구액이 비어 있고 `미청구` 라고 적힌 행이 있습니다
    - 발송 기록이 없다고 표시된 행이 있습니다
    - 원본 세 파일은 그대로입니다 (수정 날짜가 안 바뀌었습니다)

!!! warning "이렇게 나왔다면"
    - **118행이 나왔다** → 청구서 두 개만 합친 것입니다. **"발송내역.xlsx도 같이 읽었는지 확인해줘. 안 읽었으면 왜 안 읽었는지 먼저 말해줘"**
    - **116행이 나왔다** → 짝이 안 맞는 건이 사라졌습니다. **"양쪽 중 한쪽에만 있는 건이 몇 건인지 세어서, 지우지 말고 표시로 남겨줘"**
    - **120행이 나왔다** → 청구서에만 있는 건이 빠졌습니다. 같은 문장으로 물어보세요
    - 원본 파일 수정 날짜가 오늘로 바뀌었다 → **"원본 세 파일은 건드리지 말고, 결과만 새 파일에 쓰도록 다시 해줘"**
    - 두 회사 금액이 그냥 한 칸에 섞여 있다 → **"이 금액이 부가세가 포함된 금액인지 아닌지 칸을 따로 만들어 적어줘"**

??? note "왜 '옆에 있는 엑셀들'이라고 하면 안 될까요"
    결과가 틀렸을 때 **무엇을 읽었는지 확인할 방법이 없어지기 때문**입니다. "옆의", "이거", "아까 그거"는 사람끼리는 통하지만, 나중에 되짚을 때는 아무것도 가리키지 않습니다.

    원본을 건드리지 말라는 한 줄도 같은 이유입니다. 받은 파일이 정리되면서 바뀌면, 무엇이 원래 값이었는지 확인할 방법이 사라집니다.

## 이 단계 결과물 규격

`물류비_점검표.xlsx`

| 시트 | 칸 이름 (이 순서, 이 표기) | 행 수 |
|---|---|---|
| `건별판정` | 송장번호 / 발송일 / 택배사 / 정당요금 / 청구액 / 차액 / 판정 / 근거요금구간 / 적용할증 / 적용할인 | 122 |

(`정당요금`·`차액`·`판정`·`근거요금구간`·`적용할증`·`적용할인` 칸은 3단계에서 채웁니다. 지금은 칸만 있어도 됩니다)

**값 표기 규칙**

| 칸 | 규칙 |
|---|---|
| 날짜 | `2026-09-30` 한 가지 형태로 통일합니다. `2026. 9. 30.` · `2026년 9월 30일` 을 섞지 않습니다 |
| 금액 | 숫자만. 원 표시·쉼표·괄호를 쓰지 않습니다. 부가세 포함 여부는 별도 칸으로 |
| `판정` | `정상` / `과청구` / `과소청구` / `판정보류` / `발송기록없음` / `미청구` — **이 여섯 개 밖의 표현을 쓰지 않습니다** |
| 빈칸 | 값이 없으면 `0`이 아니라 비워두거나 위 라벨 중 하나로 표시합니다. 추측해서 채우지 않습니다 |
