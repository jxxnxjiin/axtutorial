# 1단계 · 작업지침을 범용 스킬로 만들기

주문통합 작업지침은 규칙이 잘 짜여 있지만, 파일명(`웹주문.xlsx`…)과 열 이름이 그대로 박혀 있습니다. 다음 달에 파일 이름 하나만 바뀌어도 못 씁니다. AI에게 이 지침을 **어떤 폴더에서도 돌아가는 범용 스킬**로 고쳐 달라고 시킨 뒤, 그 스킬로 주문이 그대로 통합되는지 확인합니다.

## 직접 시켜보세요

여러분 문장으로 AI에게 시킵니다. 아래 두 체크리스트를 먼저 읽고, 빠진 규칙이 없도록 프롬프트에 담으세요.

## 프롬프트에 꼭 담을 것 ✅

- [ ] **고칠 대상** — 지금 있는 작업지침을 재사용 가능한 스킬 문서로
- [ ] **하드코딩 제거** — 특정 파일명·열 이름에 묶지 말고, 열의 **뜻**으로 매핑하도록
- [ ] **애매하면 질문** — 뜻이 불분명한 열은 넘겨짚지 말고 나에게 되묻게
- [ ] **검산 내장** — 통합 후 행 수 = 각 파일 행 수 합 − 중복 제거 건수를 스킬이 스스로 확인하도록
- [ ] **바로 검증** — 만든 스킬로 지금 주문 3파일을 실제로 통합해 결과 파일 만들기

## 이런 건 빼세요 ❌

- [ ] `웹주문.xlsx`·`전화주문.csv` 같은 **파일명을 지침에 그대로 남기기** (다음 달에 못 씀)
- [ ] "알아서 범용으로 해줘"처럼 **범용의 기준 없는 지시**
- [ ] 뜻 모르는 열을 **임의로 매핑**하기

## 모범 프롬프트

여러분 문장을 먼저 보낸 뒤에 열어보세요.

??? example "이렇게 시킬 수 있습니다"
    ```
    1.주문통합 폴더의 '주문통합_작업지침.md'를 재사용 가능한 스킬 문서로 고쳐줘.
    특정 파일명이나 열 이름에 묶지 말고, 열이 무슨 뜻인지로 표준 칸에 매핑하도록 범용화해줘.
    뜻이 애매한 열은 넘겨짚지 말고 나에게 먼저 물어보고, 통합 후에는
    '통합 행 수 = 각 파일 행 수 합 − 중복 제거 건수'가 맞는지 스스로 검산하는 규칙도 넣어줘.
    그런 다음 그 스킬대로 이 폴더의 주문 3파일을 실제로 통합해서 결과 파일을 만들어줘.
    ```

    `3.스킬예시/SKILL.md`가 이렇게 만들어진 스킬의 완성 예시입니다. 내 스킬과 비교해 보세요.

## 체크포인트

- [ ] 스킬 문서에 **특정 파일명·열 이름이 박혀 있지 않다** (열의 뜻으로 매핑)
- [ ] 스킬에 **애매하면 되묻기** 규칙과 **검산** 규칙이 들어 있다
- [ ] 그 스킬로 통합한 주문 결과의 **행 수가 검산과 맞는다**
