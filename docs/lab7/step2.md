# 2단계 · 만든 스킬로 견적 통합하기

이제 재료를 바꿉니다. 거래처 3곳 견적 파일은 주문과 열 이름도 다르고 csv·xlsx가 섞여 있습니다. 새 지침을 또 쓰지 않고, 1단계에서 만든 **같은 스킬**을 불러와 통합되는지 봅니다. 절차는 그대로, 바뀐 건 데이터뿐이라는 걸 확인하는 단계입니다.

## 직접 시켜보세요

만든 스킬을 견적 폴더에 그대로 적용시킵니다. 통합 뒤에는 반드시 스스로 검산하게 합니다.

## 프롬프트에 꼭 담을 것 ✅

- [ ] **쓸 도구** — 새로 설명하지 말고 1단계에서 만든 스킬을 그대로 사용
- [ ] **대상 폴더** — 견적 3파일 전부(csv·xlsx 섞여 있어도)
- [ ] **열 매핑 확인** — 열 이름이 제각각이니, 매핑표를 먼저 보여주고 진행
- [ ] **같은 품목 모으기** — 같은 물품끼리 묶어 단가를 비교할 수 있게
- [ ] **통합 검산** — 통합 행 수 = 세 파일 행 수 합 − 중복 제거 건수

## 이런 건 빼세요 ❌

- [ ] 견적용으로 **규칙을 처음부터 다시** 설명하기 (스킬을 쓰는 의미가 없어짐)
- [ ] 매핑을 **확인 없이** 통째로 맡기기 (열 뜻을 넘겨짚습니다)
- [ ] 값이 없는 칸을 **0이나 임의값**으로 채우기

## 모범 프롬프트

??? example "이렇게 시킬 수 있습니다"
    ```
    아까 만든 데이터통합 스킬을 써서 2.견적통합 폴더의 견적 3파일을 하나의 비교표로 합쳐줘.
    파일마다 열 이름이 다르니 표준 칸으로 어떻게 매핑할지 표로 먼저 보여주고, 확인받은 다음 진행해줘.
    같은 품목끼리 모아 단가를 비교할 수 있게 정리하고,
    통합 행 수 = 세 파일 행 수 합 − 중복 제거 건수가 맞는지 검산표로 보여줘.
    ```

## 체크포인트

- [ ] 새 지침 없이 **1단계 스킬만으로** 견적이 통합됐다
- [ ] 열 이름이 달라도 **표준 칸으로 매핑**돼 같은 품목이 모여 있다
- [ ] 통합 행 수가 **검산과 맞고**, 값 없는 칸이 0이 아니라 빈칸이다
