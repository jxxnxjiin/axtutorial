# 1단계 · 하나의 표로 합치기

계약서 PDF를 하나 열어 보세요. 어디에도 표가 없는 줄글이고, 같은 금액도 '₩9,000,000'과 '금 구백만원정'처럼 문서마다 다르게 적혀 있습니다. AI는 이런 문서에서 항목을 뽑아 표로 만드는 일을 생각보다 빨리 해냅니다.

다만 아무런 지침 없이 작업을 시키면 AI는 문서에 없는 항목도 그럴듯하게 채워 넣기도 합니다. 따라서 계약서에서 뽑아낼 항목 6개를 못 박고, "없으면 비워둘 것"을 지침에 포함하는 것이 중요합니다.

## 뽑을 항목 여섯 개

> 계약번호 / 계약명 / 상대방 / 계약기간 / 금액 / 자동갱신 여부

## 직접 시켜보세요

여러분 문장으로 AI에게 시킵니다. 아래 두 체크리스트를 먼저 읽고 빠진 규칙이 없도록 프롬프트에 담으세요.

## 프롬프트에 꼭 담을 것 ✅

- [ ] **뽑을 항목** — 계약번호·계약명·계약 상대·계약기간·금액·자동갱신 여부
- [ ] **없는 값 처리** — 안 적힌 항목은 지어내지 말고 빈칸
- [ ] **빈 금액 처리** — 금액 조항이 없으면 0이 아니라 빈칸
- [ ] **읽을 대상** — 폴더의 계약서 8건 전부, 한 계약당 한 줄
- [ ] **결과 파일** — 하나의 엑셀 파일, 파일명 지정 (예: `계약종합.xlsx`)

## 이런 건 빼세요 ❌

- [ ] "알아서 잘 정리해줘"처럼 **규칙 없는 지시** (없는 값이 채워집니다)
- [ ] 빈칸을 `0`으로 채우기 (금액 0원과 "금액 모름"은 다른 의미입니다)

## 예시 프롬프트

여러분 문장을 먼저 보낸 뒤에 열어보세요.

??? example "이렇게 시킬 수 있습니다"
    ```
    이 폴더의 계약서 8건을 전부 읽고, 한 계약당 한 줄로 계약종합.xlsx에 정리해줘.
    각 줄에 계약번호·계약명·계약 상대·계약기간·금액·자동갱신 여부 6개 항목을 채워.
    계약서에 안 적힌 항목은 지어내지 말고 빈칸으로 두고, 특히 금액 조항이 없으면 0이 아니라 빈칸으로 남겨.
    항목을 마음대로 더하거나 바꾸지 말고 위 6개만 뽑아줘.
    다 되면 몇 건을 정리했는지와 빈칸으로 남긴 칸이 있는 계약을 알려줘.
    ```

## 체크포인트

- [ ] 결과 파일이 **8행**(계약 8건, 한 건당 한 줄)으로 나왔다
- [ ] **금액이 없는 계약이 빈칸**으로 남아 있다 (0이 아님)
- [ ] 6개 항목이 모두 채워졌고, 없는 값을 지어내지 않았다
