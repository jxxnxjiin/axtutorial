# 2단계 · 원본과 대조해 검산

표가 그럴듯해 보여도 그대로 믿으면 안 됩니다. **그럴듯한 게 가장 위험합니다.** 사람이 8건을 일일이 못 보니, AI에게 **자기 답을 스스로 검산**하게 시켜 지어낸 값을 잡습니다.

## 직접 시켜보세요

1단계에서 만든 엑셀 파일을 놓고, 아래와 같은 내용들을 AI에게 검증합니다.

## 검증에 포함해볼 것 ✅

- [ ] **내용의 근거 물어보기** — 원문에서 근거 문장을 찾을 수 없는 칸을 정리하도록 합니다.
- [ ] **금액 빈칸 유지 확인** — 금액이 없던 계약의 칸이 빈칸인지, 0이나 다른 임의 숫자로 채워지지는 않았는지 확인합니다. 
- [ ] **경계 계약 확인** — `CT-2026-004`(재계약 필요 → 자동갱신 **아니오**) / `CT-2026-005`(해지 통보 없으면 자동연장 → **예**)가 반대로 되어 있지 않은지 확인합니다.

## 이런 건 빼세요 ❌

- [ ] 그냥 **"맞아?"** 라고만 묻기 (AI는 "맞다"고 답하기 쉽습니다)
- [ ] 표본 **한두 건만** 보고 넘어가기 (틀린 건 안 본 곳에 숨어 있습니다)

## 체크포인트

- [ ] AI에게 **지어낸 값을 자수**시켰고, 걸린 칸은 원문 대조로 고쳤다
- [ ] 금액이 없던 계약이 **여전히 빈칸**이다
- [ ] `CT-2026-004` · `CT-2026-005`의 자동갱신 여부가 **근거대로** 맞다
