# 2단계 · 쿠폰별로 성과 집계하기

1단계에서 모은 주문 9천여 건을 쿠폰 44개에 대한 집계로 줄여, 빈 성과표의 각 칸을 계산해 채웁니다. 한 쿠폰이 한 줄입니다.

## 채울 칸과 계산 규칙

> 매출합계 = 결제완료 `매출액_원` 합 · 할인합계 = 결제완료 `할인액_원` 합

> **매출이익 = 매출합계 × 30%** · 순이익 = 매출이익 − 할인합계

> 매출순이익률 = 순이익 ÷ 매출합계 · 사용건수 = 결제완료 건수 · 적자여부 = 순이익 < 0 이면 `적자`

## 직접 시켜보세요

아래 두 체크리스트를 먼저 읽고, 빠진 규칙이 없도록 프롬프트에 담아보세요.

## 프롬프트에 꼭 담을 것 ✅

- [ ] **집계 대상** — 1단계에서 만든 통합 파일을 `쿠폰코드`로 묶기 (쿠폰 44개)
- [ ] **거를 것** — `주문상태`가 취소인 건 빼고 **결제완료만**
- [ ] **채울 칸** — 위 7칸, 계산식 그대로 (마진율은 **매출의 30%**)
- [ ] **결과 파일** — 채운 집계표, 파일명 지정 (예: `쿠폰별성과표.xlsx`)

## 이런 건 빼세요 ❌

- [ ] **취소 주문까지 포함**해 집계 (밑지는 쿠폰이 흑자로 둔갑합니다)
- [ ] 매출합계·할인합계 없이 **순이익만** 남기기 (검산·역추적이 막힙니다)
- [ ] "알아서 분석까지 해줘"처럼 **규칙 없는 지시**

## 예시 프롬프트

여러분 문장을 먼저 보낸 뒤에 열어보세요.

??? example "이렇게 시킬 수 있습니다"
    ```
    1단계에서 만든 주문종합.xlsx를 쿠폰코드로 묶어서 7.쿠폰별성과표.xlsx의 각 칸을 채워줘.
    주문상태가 '취소'인 건 빼고 '결제완료'만 집계해.
    쿠폰마다: 매출합계=매출액_원 합, 할인합계=할인액_원 합,
    매출이익=매출합계×0.3, 순이익=매출이익−할인합계,
    매출순이익률=순이익÷매출합계, 사용건수=결제완료 건수,
    순이익이 마이너스면 적자여부에 '적자'라고 적어줘.
    다 되면 채운 줄 수와, 결제완료로 집계한 총 건수를 알려줘.
    ```
