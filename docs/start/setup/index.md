# 0. 개발 환경 세팅 — 개요

!!! abstract "이 섹션에서 하는 일"
    - 오늘 실습에 쓸 도구 세 종류가 각각 **무슨 역할**인지 이해합니다
    - 그다음 페이지에서 하나씩 **설치**하고, 마지막에 **로그인·데이터 준비**까지 끝냅니다

바이브코딩 실습을 시작하기 전에, 오늘 설치할 도구들이 각각 어떤 역할인지 짚고 갑니다. **'전문적인 작업 공간(워크스페이스)'을 세팅한다**고 생각하면 이해하기 쉽습니다.

---

## 오늘 세팅할 세 가지

### ① VS Code — "메인 작업 공간(에디터)"

문서를 쓸 때 '워드'나 '한글'을 켜는 것처럼, **코드를 작성하고 확인하는 기본 툴**입니다. 앞으로의 바이브코딩 실습은 모두 이 프로그램 화면 안에서 이루어집니다. 우리의 모든 작업이 모이는 **널찍한 책상**이라고 보면 됩니다.

### ② 언어 설치(Python, Node.js) — "전문 작업 도구 및 인프라"

책상(VS Code)이 준비됐다면, 그 위에서 목적에 맞게 쓸 전문 도구들이 필요합니다.

- **Python(파이썬)** — 데이터 처리와 AI 작업에 특화된 도구입니다. 이번 실습에서는 PDF·이미지 데이터를 분석하고 가공하는 데 씁니다.
- **Node.js(노드제이에스)** — 웹 서비스를 화면에 띄우고(프론트엔드), 데이터를 처리하는 서버(백엔드)를 구동하는 **필수 인프라 환경**입니다.

### ③ AI 코딩 에이전트 — "실무를 돕는 AI 어시스턴트"

바이브코딩의 핵심 도구입니다. 과거에는 작업자가 직접 복잡한 프로그래밍 문법을 배워 코드를 작성해야 했지만, 이제는 작업 공간(VS Code)에 AI 어시스턴트를 연동해 활용합니다.

우리가 일상 언어로 **"이런 데이터를 처리하는 기능을 만들어줘"**라고 지시하면, AI 어시스턴트가 의도를 파악해 실제 코드로 구현해 줍니다. 대표적으로 **Claude Code**가 있으며, 본인의 작업 스타일이나 구독 중인 계정에 맞는 에이전트를 골라 설치할 수 있습니다.
