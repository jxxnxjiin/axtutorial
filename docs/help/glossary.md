# 이 말이 무슨 뜻이죠

!!! abstract "이 페이지가 하는 일"
    - 오늘 나오는 말들을 한 줄로 풀어둡니다
    - 복습용입니다. 실습 중에 여기부터 읽을 필요는 없습니다

---

## 도구와 화면

| 말 | 한 줄 풀이 |
|---|---|
| **터미널** | 명령을 글자로 입력하는 까만 화면. VS Code 아래쪽에 열립니다 |
| **VS Code** | 파일을 열고 편집하는 프로그램. 오늘은 여기서 폴더를 열고 터미널을 씁니다 |
| **폴더 열기** | VS Code에 "이 폴더 전체를 봐라"라고 알려주는 것. 파일 하나만 열면 옆의 파일들을 못 봅니다 |
| **프롬프트** | AI에게 시킬 때 쓰는 문장 |
| **자동 승인** | 파일을 고칠 때마다 뜨는 확인 창을 미리 꺼두는 설정 |
| **스킬** | 자주 쓰는 작업 방식을 미리 담아둔 도구. `/` 로 시작하는 이름으로 부릅니다 |
| **브라우저** | 인터넷 화면을 보는 프로그램 (크롬·엣지·사파리 등) |
| **html 파일** | 브라우저에서 열리는 화면 파일. 더블클릭하면 열립니다 |
| **캡처** | 지금 화면을 그림으로 저장하는 것 |

---

## 파일과 데이터

| 말 | 한 줄 풀이 |
|---|---|
| **시트** | 엑셀 파일 안의 탭 하나. 한 파일에 여러 장이 들어갑니다 |
| **행 / 열** | 가로 한 줄이 행, 세로 한 칸이 열 |
| **CSV** | 쉼표로 칸을 나눈 표 파일. 엑셀로 열립니다 |
| **PDF** | 인쇄용으로 굳어진 문서 파일 |
| **스캔된 PDF** | 종이를 사진으로 찍어 넣은 PDF. 글자를 마우스로 긁을 수 없습니다 |
| **RSS** | 새 글이 올라올 때마다 목록으로 내보내는 주소. 공고를 자동으로 가져올 때 씁니다 |
| **원본 보존** | 받은 파일을 고치지 않고 읽기만 하는 것. 결과는 새 파일에 씁니다 |
| **두 표를 짝지어 붙이기** | 공통된 값(예: 송장번호)을 열쇠 삼아 두 표를 한 표로 합치는 것 |
| **뽑아내기** | 문서나 사진에서 필요한 값만 골라내 표로 만드는 것 |

## 오늘 쓰는 표시들

| 말 | 한 줄 풀이 |
|---|---|
| **판독불가** | 글자가 확실히 안 보여서 값을 못 읽은 칸. 추측해서 채우지 않습니다 |
| **판정보류** | 근거가 부족해 판정을 미룬 건 |
| **발송기록없음** | 청구서에는 있는데 우리 기록에 없는 건 |
| **미청구** | 우리 기록에는 있는데 청구서에 없는 건 |
| **문서없음** | 대장에는 있는데 계약서 파일이 없는 건 |
| **판단보류** | 우리 일인지 애매해서 결정을 미룬 공고 |
| **번복됨** | 뒤에서 뒤집힌 앞의 결정. 지우지 않고 남깁니다 |
| **미정** | 아직 정해지지 않은 값 |
| **확인필요** | 사람이 확인해야 하는 값 |

**전부 같은 이야기입니다** — **모르는 건 지어내지 말고 표시로 남긴다.**

## 자주 나오는 표현

| 말 | 한 줄 풀이 |
|---|---|
| **AI가 없는 걸 지어낸다** | 자료에 없는 값을 그럴듯하게 만들어 채우는 것. 그래서 근거를 같이 요구합니다 |
| **사진 속 글자 읽기** | 사진이나 스캔 문서에서 글자를 읽어내는 것 |
| **다음에도 쓰게 설명서로 남기기** | 오늘 한 절차를 파일로 적어두는 것. 파일 이름은 `SKILL.md` |
| **프로젝트 규칙 메모** | 매번 안 알려줘도 되게 규칙을 적어두는 파일 |
| **국소 수정** | 고칠 곳만 지정해서 고치게 하는 것. "전부 다시"라고 하지 않습니다 |
| **검산** | 만든 것을 **바깥에 있는 것**(원본 사진·PDF·시트)과 맞대보는 것 |
