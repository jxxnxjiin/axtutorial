# AI에게 잘 시키는 법

!!! abstract "이 페이지가 하는 일"
    - 오늘 여러분이 채워가는 목록이 여기 있습니다
    - 지금은 비어 있습니다. 한 단계씩 겪을 때마다 여러분 말로 한 줄씩 채웁니다

---

## 내 문장에 이게 있나

!!! quote "오늘 채워가는 다섯 줄"
    1. <span class="blank-line">________________________________________________________</span>
    2. <span class="blank-line">________________________________________________________</span>
    3. <span class="blank-line">________________________________________________________</span>
    4. <span class="blank-line">________________________________________________________</span>
    5. <span class="blank-line">________________________________________________________</span>

**이건 "이렇게 쓰세요"가 아니라 "내 문장에 이게 있나"입니다.** 검사 항목이지 틀이 아닙니다.

채우는 때는 정해져 있습니다. **각 실습의 1단계에서 여러분 문장을 한 번 보낸 직후**입니다. 아래 "목록을 스스로 채우게 하는 한 줄"을 그대로 보내면, 돌아온 답이 그 줄의 재료가 됩니다.

[실습 1](../lab1/step1.md)·[실습 2](../lab2/step1.md)·[실습 3](../lab3/step1.md)을 지나면서 다섯 줄이 대체로 채워집니다. [실습 4](../lab4/index.md) 이후로는 새 줄이 잘 안 늘고, 이미 적어둔 줄을 **그대로 꺼내 쓰기만** 하게 됩니다. 그게 정상입니다.

!!! danger "이 다섯 줄을 미리 채워달라고 AI에게 시키지 마세요"
    겪고 나서 자기 말로 적는 것이 이 목록의 전부입니다. 미리 채우면 오늘 겪을 것이 통째로 사라집니다.

---

## 목록을 스스로 채우게 하는 한 줄

각 단계에서 **자기 문장을 한 번 보낸 뒤**, 이 문장을 그대로 보내보세요.

!!! quote "이 한 줄은 복사해서 그대로 쓰세요 — 오늘 복사를 권하는 유일한 문장입니다"
    ```
    내가 이렇게 시키려고 해: (여러분이 방금 쓴 문장)
    이대로 하면 네가 임의로 정하게 되는 게 뭐야? 그것만 알려줘.
    고쳐 쓴 문장은 주지 말고, 아직 하지도 마.
    ```

뒤의 두 조건이 중요합니다.

- **"고쳐 쓴 문장은 주지 마"**가 없으면 완성된 문장을 뱉고, 여러분은 그걸 복사하게 됩니다
- **"아직 하지 마"**가 없으면 그냥 진행해버려서 어긋난 장면을 볼 기회가 사라집니다

돌아온 답이 그대로 위 다섯 줄의 재료가 됩니다.

---

## 시키기 전에 세 가지

목록이 비어 있는 지금은 이 셋만 기억하면 됩니다.

| | 무엇을 말하나 | 예 |
|---|---|---|
| **무엇을** | 어느 파일·폴더를 보라는 건지 **이름으로** | "웹주문·전화주문·제휴주문 세 파일을" |
| **어떻게** | 어떤 순서로, 무엇을 기준으로 | "작업방법참고의 대조표를 기준으로 맞춰서" |
| **어떤 모양으로** | 결과를 어떤 이름의 파일에 어떤 칸으로 | "주문종합.xlsx의 표준 7칸에" |

**"AI에게 물어본다"가 아니라 "AI에게 시킨다"입니다.** 시키는 쪽이 정할 것을 정해야 받는 물건이 쓸 만해집니다.

---

## AI가 되물으면

그건 AI가 잘못한 게 아니라 **여러분이 안 말한 것**입니다.

되물은 내용을 그대로 목록에 적으세요. 그게 다음번에 먼저 말해야 할 내용입니다.

---

## 결과를 받은 뒤

| 하는 것 | 안 하는 것 |
|---|---|
| 폴더를 열어 파일이 생겼는지 본다 | "완료했습니다"를 믿는다 |
| 행 수를 센다 | "다 넣었습니다"를 믿는다 |
| **원본**(사진·PDF·시트)과 맞대본다 | AI에게 "맞는지 확인해줘"라고만 한다 |
| 고칠 곳을 짚어준다 | "전부 다시 써줘"라고 한다 |

마지막 줄이 특히 중요합니다. AI에게 "맞는지 확인해줘"라고만 하면, **자기가 만든 걸 자기가 읽고 "맞습니다"**라고 합니다.
