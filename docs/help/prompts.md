# 오늘 내가 친 문장

!!! abstract "이 페이지가 하는 일"
    - **여러분이 오늘 직접 친 문장**을 여기에 옮겨 적습니다
    - 강사가 채워주지 않습니다. 완성 문장 창고가 아닙니다

집에 가져가는 물건은 이 페이지입니다. **내일 처음 보는 일 앞에서 열 페이지**니까요.

---

## 옮겨 적는 법

각 실습을 끝낼 때마다, Claude Code 화면을 위로 올려 **여러분이 친 문장**을 찾아 여기에 옮겨 적으세요. 종이에 적어도 되고, 이 페이지를 복사해 메모장에 붙여넣고 채워도 됩니다.

**AI가 답한 것은 적지 않습니다. 여러분이 친 것만 적습니다.**

## 옮겨 적으면서 보게 되는 것

세 가지를 세어보세요.

- 처음 친 문장과 고쳐 친 문장의 **길이 차이**
- 고쳐 친 문장에 다섯 줄 중 **몇 개**가 들어 있는지
- 일곱 실습을 지나면서 **처음 문장이 길어졌는지**

세 번째가 오늘의 결과입니다. 몇 개였든 상관없습니다. 오늘 아침보다 늘어난 상태입니다.
