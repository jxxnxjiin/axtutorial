# 여유 실습 A · 회의 녹취에서 결정사항과 할 일 뽑기

<span class="route-badge">:material-run-fast: **혼자 완주하는 실습입니다.** 강사가 진행하지 않습니다. 위키만 보고 끝까지 갈 수 있게 썼습니다</span>

**한 줄 목표: 오간 말 중에서 진짜 결정만 골라내고, 각 줄이 어디서 나왔는지 근거를 남긴다.**

예상 소요 **40분 이상**. 강의 중에 시간이 남았거나, 집에 가서 이어서 할 때 하세요.

---

## 받은 일

> 사수가 말합니다.
>
> "지난 3주 팀 회의 녹취 파일이에요. 자동 녹취라 정리가 하나도 안 돼 있어요. 여기서 뭘 하기로 했고, 누가 언제까지 하는 건지만 뽑아서 표로 주세요."

파일 세 개에 **720줄**이 넘습니다. 회의 안건과 상관없는 잡담도 섞여 있고, 앞에서 정한 걸 뒤에서 뒤집은 것도 있습니다.

!!! info "줄 번호 규약"
    줄 번호는 **빈 줄을 포함한 물리 줄 번호**이고 1부터 셉니다. 메모장이나 VS Code 왼쪽에 보이는 그 번호가 맞습니다. 3단계에서 이 번호를 씁니다.

## 혼자 하는 실습이라 힌트를 여는 기준이 다릅니다

강의실 시계가 없으므로 **왕복 횟수**로 엽니다.

| 상자 | 여는 기준 |
|---|---|
| **① 질문 하나** | 두 번 시켜봤는데도 안 되면 |
| **② 정해야 할 것들** | 세 번째에도 안 되면 |
| **③ 모범답안** | 한 번 시켜본 뒤라면 언제든 |

## 다섯 줄 (완성본)

본 실습에서는 이 목록을 여러분이 직접 채웠습니다. 이 페이지는 강의가 끝난 뒤 보는 페이지라 완성본을 실어둡니다.

!!! quote "내 문장에 이게 있나"
    1. 어느 파일을 보라는 건지 **이름으로** 말했나 (원본은 건드리지 말라는 말까지)
    2. 애매한 게 나오면 **어떻게 하라고** 말했나
    3. 결과를 **어떤 이름의 파일에, 어떤 모양으로** 받겠다고 말했나
    4. **어디까지 되면 다 된 건지** 말했나
    5. **내가 확신 없는 게 뭔지** 말했나

이 실습을 하면서 이 다섯 줄이 여러분 문장에 몇 개나 들어갔는지 세어보세요.
