# 막혔을 때 쓰는 문장들

!!! abstract "이 페이지가 하는 일"
    - 화면이 안 열리거나 깨졌을 때 그대로 복사해 쓸 문장들
    - 에러를 붙여넣을 때 같이 보낼 한 줄

이 페이지는 **실습 4 어느 단계에서든** 열어도 됩니다.

---

## 먼저 붙일 한 줄

에러를 그대로 붙여넣기만 하면 상황을 몰라 여러 번 오갑니다. **아래 한 줄을 같이 보내면 왕복이 절반으로 줍니다.**

!!! quote "짐작 한 줄"
    ```
    지금 (어느 단계)에서 (어떤 파일)을 (어떻게) 했더니 났어. 내 짐작엔 (          ) 때문인 것 같아.
    ```

**짐작이 틀려도 됩니다. 틀린 짐작도 단서입니다.**

---

## 상황별로 그대로 쓸 문장

| 상황 | 그대로 복사할 문장 |
|---|---|
| 화면이 안 열린다 | `화면이 안 열려. 지금 뭘 해야 볼 수 있는지 순서대로 알려줘.` |
| 빨간 글씨가 떴다 | (에러 메시지를 통째로 붙여넣고) `이 오류가 났어. 고쳐줘.` |
| 글자가 깨진다 | `글자가 깨져서 나와.` |
| 한 번에 너무 많이 한다 | `한 번에 다 하지 말고, 지금은 표만 보이게 해줘.` |
| 되돌리고 싶다 | `지금 상태를 되돌리고 싶어. 바로 전으로 돌려줘.` |
| 파일을 못 찾는다고 한다 | `지금 폴더에 어떤 파일이 있는지 목록으로 보여줘.` |
| 표가 안 보인다 | `표가 화면에 안 보여. 지금 표가 몇 행 들어가 있는지 먼저 알려줘.` |
| 숫자가 이상하다 | `이 숫자를 어느 파일 어느 시트에서 가져왔는지 알려줘.` |
| 화면이 통째로 망가졌다 | `방금 변경을 되돌려줘.` |

---

## 그래도 안 되면

`lab4/못따라왔을때/dashboard_기본.html` 을 더블클릭해서 여세요.

**3단계(Before 캡처)부터 7단계까지는 이 파일로도 전부 성립합니다.** 캡처하고, 디자인 입히고, 비교하고, 검산하는 것이 이 실습의 본체입니다.

!!! info "실습 1·2에서 파일 이름을 바꿨다면"
    2단계에서 파일을 못 찾는 게 당연합니다. 이건 힌트로 풀리는 문제가 아닙니다. **힌트를 더 열지 말고 위 파일을 바로 여세요.**

---

## 빨간 글씨는 정상입니다

오전에 들은 규칙 그대로입니다. 직접 해석하려고 애쓰지 마세요. **있는 그대로 전달하는 것**이 핵심입니다.
