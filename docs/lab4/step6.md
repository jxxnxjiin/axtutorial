# 6. 다크모드·반응형 한 마디로 켜기

!!! abstract "이 단계에서 하는 일 (약 1분)"
    - 고른 화면에 원하는 것 **하나만** 얹어봅니다
    - 한 문장이면 됩니다

1분짜리 단계입니다. 시간이 밀렸으면 통째로 건너뛰어도 됩니다.

---

## 하나만 골라 한 문장으로

!!! quote "그대로 복사해서 쓰세요 — 하나만"
    ```
    다크모드도 되게 해줘.
    ```
    ```
    휴대폰 화면에서도 안 깨지게 해줘.
    ```
    ```
    표가 길면 표 안에서만 스크롤되게 해줘.
    ```
    ```
    /impeccable 로 버튼이랑 여백, 문구를 다듬어줘.
    ```

!!! success "이렇게 나오면 정상입니다"
    - 화면을 새로고침하면 요청한 것이 반영돼 있습니다
    - 표 행 수와 맨 위 숫자는 그대로입니다

!!! warning "이렇게 나왔다면"
    - 화면이 깨졌다 → **"방금 변경을 되돌려줘"**
    - 표 내용이 바뀌었다 → **"숫자와 표 내용은 그대로 두고 보이는 모양만 바꾸는 걸로 다시 해줘"**

---

!!! example "이게 어떻게 되는 건지 궁금하다면"
    **그건 오늘 몰라도 됩니다.** 예전엔 며칠 걸리던 것들이 지금은 한 문장이라는 것만 보시면 됩니다.

---

**체크포인트**

- [ ] 하나를 골라 한 문장으로 시켰다
- [ ] 화면을 새로고침해서 반영된 걸 확인했다
- [ ] 표 행 수와 맨 위 숫자가 그대로다
