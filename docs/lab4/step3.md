# 3. Before 캡처하기

!!! abstract "이 단계에서 하는 일 (약 3분)"
    - 지금 화면을 그대로 캡처합니다
    - `before.png` 라는 이름으로 작업 폴더에 저장합니다

**3분이 아까워 보여도 자르지 마세요.** 이걸 안 하면 마지막 비교가 성립하지 않습니다.

---

## 캡처하는 법

| | 방법 |
|---|---|
| 윈도우 | <kbd>Windows</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> → 영역 선택 → 그림판에 붙여넣고 저장 |
| 맥 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>4</kbd> → 영역 선택 (바탕화면에 저장됩니다) |

저장한 파일을 **`시작폴더/`** 안에 `before.png` 라는 이름으로 옮기세요.

---

!!! success "이렇게 나오면 정상입니다"
    - `시작폴더/` 안에 `before.png` 가 있습니다
    - 캡처에 **맨 위 숫자 3개와 표가 같이** 들어 있습니다

!!! warning "이렇게 나왔다면"
    - 표가 잘려 나왔다 → 브라우저를 축소(<kbd>Ctrl</kbd>+<kbd>-</kbd>)하고 다시 캡처하세요. 전체가 한 장에 들어가는 게 좋습니다
    - 어디에 저장됐는지 모르겠다 → **"방금 만든 화면 폴더에 png 파일이 있는지 확인하고 경로를 알려줘"**

??? note "왜 지금 캡처할까요"
    다음 단계부터 화면의 인상이 바뀝니다. **바뀌기 전 모습이 없으면 무엇이 달라졌는지 말할 수 없습니다.**

    그리고 오늘 마지막에 Before/After를 나란히 보는 자리가 있습니다. 그때 쓸 사진입니다.

---

**체크포인트**

- [ ] `before.png` 가 작업 폴더에 있다
- [ ] 캡처에 숫자 3개와 표가 같이 들어 있다
- [ ] 파일을 더블클릭해서 그림이 제대로 열린다
