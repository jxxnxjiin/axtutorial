# 1. 무엇을 보여줄지 먼저 쓰기

!!! abstract "이 단계에서 하는 일 (약 10분)"
    - 화면에 무엇이 보여야 하는지 네 줄로 적습니다
    - 색으로 구분할 기준에 **숫자**를 넣습니다
    - 아직 화면은 만들지 않습니다

빈 화면부터 만들지 않습니다. **무엇을 볼지 먼저 정합니다.** 화면을 만드는 일의 절반이 이 일입니다.

---

## `대시보드에_보일_것.md` 를 만드세요

`시작폴더/` 안에 이 이름으로 파일을 만들고, 아래 네 줄을 여러분 손으로 채웁니다.

```
맨 위에 크게 보일 숫자 3개:  ___ / ___ / ___
표로 보일 것:               ___
색으로 구분할 것:           ___
눌러서 걸러볼 것:           ___
```

!!! example "채우기 전에 한번 보세요"
    실습 1·2에서 만든 엑셀 두 개를 열어두고 채우면 훨씬 빠릅니다. **거기 없는 숫자는 화면에도 못 올립니다.**

---

??? question "① 3분이 지나도 막막하다면 — 아직 펼치지 마세요"
    "이 화면을 보는 사람이 **30초 안에 뭘 해야 하는지** 알아야 한다"면, 맨 위에 뭐가 있어야 할까요?

??? tip "② 7분이 지났다면 — 네 줄에 각각 무엇이 들어가나"
    - **숫자 3개** — 엑셀에서 세거나 더해서 나오는 값이어야 합니다. 이름으로 적으세요
    - **표** — 어느 시트의 어느 칸들을 보여줄지
    - **색** — 무엇을 어떤 색으로 구분할지. **기준에 숫자가 들어가야 합니다** (예: 며칠 이내)
    - **거르기** — 무엇으로 걸러볼지 (예: 택배사별 / 판정별)

??? example "③ 모범답안 — 채워진 견본 1장 (여러분 것을 먼저 채워본 뒤에 여세요)"

    ```
    맨 위에 크게 보일 숫자 3개:  이번 달 과청구 총액 / 30일 내 만료 계약 수 / 판정보류 건수
    표로 보일 것:               건별판정 전체(송장번호·택배사·차액·판정) + 계약만료 전체
    색으로 구분할 것:           30일 이내 만료는 빨강 / 판정보류·문서없음은 회색 / 과청구는 주황
    눌러서 걸러볼 것:           택배사별 / 판정별
    ```

    **이 견본이 하는 일**

    | 이 칸이 | 없으면 |
    |---|---|
    | 숫자 3개를 **이름으로** 적기 | 2단계에서 아무 숫자나 위에 올라가고, 여러분은 그게 왜 싫은지 말을 못 합니다 |
    | 색 기준에 **숫자**(30일) 적기 | 디자인을 입히는 동안 기준이 60일로 슬쩍 바뀌어도 7단계에서 못 잡습니다 |

    **한 번에 잘 됐다면** — 여러분이 고른 숫자 3개와 견본의 3개가 왜 다른지 한 줄로 적어보세요. **다른 게 정상입니다.**
    **아직 막막하다면** — 이 견본을 그대로 쓰고 2단계로 가세요. 숫자 3개는 나중에 바꿔도 됩니다.

---

## 뭐가 달라졌는지 봅니다

!!! success "이렇게 나오면 정상입니다"
    - `시작폴더/` 에 `대시보드에_보일_것.md` 파일이 있습니다
    - 네 줄이 다 채워져 있습니다
    - **색 기준에 숫자가 들어 있습니다**
    - 숫자 3개가 전부 엑셀에서 세거나 더해서 나오는 값입니다

!!! warning "이렇게 나왔다면"
    - 숫자 3개가 "매출"처럼 엑셀에 없는 것이다 → 엑셀 두 개를 열어 실제로 있는 값으로 바꾸세요
    - 색 기준이 "급한 건 빨강"이다 → **며칠 이내가 급한 건지** 숫자를 넣으세요. 숫자가 없으면 나중에 대조할 수 없습니다
    - 파일을 AI에게 대신 써달라고 했다 → 여러분이 뭘 보고 싶은지는 AI가 모릅니다. 네 줄만 직접 쓰세요

??? note "이 파일이 없으면 어떻게 되나요"
    AI는 아무 화면이나 만듭니다. 그리고 여러분은 그게 마음에 안 드는데 **왜 그런지 말을 못 합니다.**

    7단계에서 "처음에 내가 뭐라고 했는지"와 최종 화면을 맞대보는 자리가 있습니다. 이 파일이 없으면 그 대조 자체가 성립하지 않습니다.
