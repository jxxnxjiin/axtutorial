# VOC 분류 키워드 기준

대상 파일:

- `1. VOC원문.xlsx`: 고객 문의 원문
- `2. VOC_분류기준.pdf`: 문의유형, 감정, 위험대응 분류 기준

목표는 모든 문장을 사람이 처음부터 읽지 않고, 키워드 규칙으로 1차 분류한 뒤 애매한 건만 2차 검토하는 것이다.

## 분류 축

각 VOC는 아래 3개 축을 독립적으로 가진다.

| 축 | 값 |
| --- | --- |
| 문의유형 | 환불취소, 배송지연, 제품하자, 사용문의, 칭찬감사, 기타 |
| 감정 | 부정, 중립, 긍정 |
| 위험대응 | Y, N |

## 1. 문의유형 기준

문의유형은 "고객이 원하는 조치"를 기준으로 1개만 부여한다.

### 우선순위

복합 문장은 아래 순서로 먼저 매칭되는 유형을 선택한다.

1. 환불취소
2. 배송지연
3. 사용문의
4. 제품하자
5. 칭찬감사
6. 기타

단, "전원이 안 켜져요, 고장인 것 같아요"처럼 하자 판단을 요구하면 `제품하자`이고, "작동하지 않는데 사용 방법이 맞는지 확인하고 싶어요"처럼 사용 방법 확인을 요구하면 `사용문의`로 본다.

### 환불취소

거래 변경, 주문 취소, 환불, 반품, 교환 요청이다.

1차 키워드:

- `환불`
- `취소`
- `반품`
- `교환`
- `중복 결제`, `결제가 중복`
- `실수로 주문`
- `마음이 바뀌`
- `색상이 사진과 달라`, `사진과 달라`
- `사이즈가 안 맞`

예시:

- `결제가 중복돼서 취소 처리해 주세요.`
- `색상이 사진과 달라서 교환 요청드립니다.`
- `받아봤는데 별로여서 반품하고 싶습니다.`

### 배송지연

미도착, 배송 지연, 택배 조회, 배송 기사 방문 여부 등 배송 상태 확인이다.

1차 키워드:

- `배송이 늦`, `배송 늦`
- `배송 지연`
- `택배 조회`
- `며칠째 그대로`
- `아직 도착 안`, `도착을 안`, `도착 안`
- `언제쯤 오`
- `일주일 지났는데`
- `택배 기사님이 방문`, `못 받았`

예시:

- `배송이 예정일보다 많이 늦어지고 있어요.`
- `택배 조회를 해보니 며칠째 그대로예요.`
- `아직 도착 안 했는데 언제쯤 오나요?`

### 사용문의

제품 사용법, 설정, 매뉴얼, 작동 방법 확인 요청이다.

1차 키워드:

- `초기 설정`
- `앱에서 설정`
- `설정을 어떻게`
- `사용법`
- `사용 방법`
- `매뉴얼`
- `방법을 알려`
- `사용 방법이 맞는지`
- `작동이 잘 안 되는데 방법`

주의:

- `궁금합니다`, `어떻게 하나요`만으로는 사용문의로 잡지 않는다.
- `이벤트 응모는 어떻게 하나요?`, `포인트 유효기간이 언제까지인가요?`, `매장 위치 좀 알려주세요.`는 `기타`가 더 적절하다.

예시:

- `초기 설정을 어떻게 하는지 궁금해요.`
- `사용법 매뉴얼이 어디 있나요?`
- `기능이 작동하지 않는데 사용 방법이 맞는지 확인하고 싶어요.`

### 제품하자

제품 자체의 불량, 파손, 고장, 하자, 전원 문제다.

1차 키워드:

- `불량`
- `파손`
- `고장`
- `하자`
- `전원이 안`
- `작동하지 않`
- `마감 부분`
- `이음새`
- `박스가 파손`

예시:

- `며칠 만에 불량이 생겼어요.`
- `이음새가 파손되어 있었어요.`
- `전원이 안 켜져요, 고장인 것 같아요.`

### 칭찬감사

별도 조치 요구 없이 만족, 감사, 칭찬이 핵심인 문장이다.

1차 키워드:

- `좋아요`
- `최고`
- `만족스럽`
- `만족도`
- `감사`
- `덕분에 잘 해결`
- `친절하게 답`
- `상담부터 응대까지`

주의:

- `배송이 늦었지만 상담원은 친절했어요`처럼 본 사안이 따로 있으면 칭찬은 부수 표현이다.
- 위험 신호가 함께 있으면 문의유형은 칭찬감사일 수 있어도 위험대응은 반드시 `Y`다.

### 기타

위 유형에 들어가지 않는 일반 문의, 잡담, 회사 정보 문의다.

예시:

- `요즘 날씨가 덥네요, 잘 지내시나요?`
- `이벤트 응모는 어떻게 하나요?`
- `포인트 유효기간이 언제까지인가요?`
- `매장 위치 좀 알려주세요.`

## 2. 감정 기준

감정은 문의유형과 별개로 판단한다.

### 부정

화남, 실망, 짜증, 불편, 지연, 하자 등 문제 상황이 본 사안인 경우다.

1차 키워드:

- `짜증`
- `최악`
- `화가`
- `실망`
- `불편`
- `별로`
- `ㅠㅠ`, `😭`
- `답변이 없`
- `해결이 안`
- `처리가 안`
- `아쉬웠`

문제 상황 키워드:

- 배송: `배송이 늦`, `아직 도착 안`, `도착을 안`, `택배 조회`, `못 받았`
- 제품: `불량`, `파손`, `고장`, `하자`, `전원이 안`, `작동하지 않`
- 거래: `환불`, `반품`, `교환`, `취소`

주의:

- `배송 지연 사유가 궁금합니다`처럼 정보 확인에 가까운 문장은 감정 표현이 없으면 `중립`으로 둔다.
- `그래도 상담원은 친절했어요`가 있어도 본 사안이 불편/지연/하자라면 `부정`으로 본다.

### 긍정

만족, 감사, 칭찬이 핵심이고 문제 상황이 본 사안이 아닌 경우다.

1차 키워드:

- `좋아`
- `최고`
- `만족`
- `감사`
- `다행`
- `친절`
- `덕분에 잘 해결`

주의:

- 긍정 키워드가 있어도 `다만 배송이 늦어진 건 화가 났어요`, `해결이 안 되면 신고`가 있으면 본 사안 기준으로 `부정` 또는 위험대응 `Y`를 우선한다.

### 중립

감정 표현 없이 사실 전달, 정보 요청, 단순 확인만 하는 문장이다.

예시:

- `배송 지연 사유가 궁금합니다.`
- `사용법 매뉴얼이 어디 있나요?`
- `결제가 중복돼서 취소 처리해 주세요.`

## 3. 위험대응 기준

위험대응은 문의유형, 감정과 무관하게 독립 스캔한다.

아래 신호가 하나라도 있으면 `Y`다.

### 법적 대응

- `법적 대응`, `법적대응`
- `변호사`
- `소비자원`
- `소비자 보호원`
- `신고`
- `고발`

### 여론 확산

- `언론`
- `제보`
- `SNS 확산`
- `확산`

### 안전 위험

- `화재`
- `부상`
- `감전`
- `유해물질`
- `다쳤`
- `위험`

주의:

- 긍정 문장이어도 위험 신호가 있으면 무조건 `Y`다.
- `정말 만족스럽게 잘 쓰고 있어요. 다만 소비자원에 신고하는 것까지 생각하고 있습니다.`는 감정과 별개로 위험대응 `Y`다.

## 4. 2차 검토 대상으로 보내야 하는 경우

아래 조건 중 하나라도 해당하면 `검토필요=Y`를 붙인다.

- 위험대응이 `Y`인 문장
- 문의유형 키워드가 2개 이상 겹친 문장
- `제품하자`와 `사용문의`가 동시에 잡힌 문장
- 긍정 키워드와 부정 키워드가 동시에 있는 문장
- 아무 키워드도 잡히지 않아 `기타`가 된 문장
- `궁금`, `어떻게`, `안내 부탁`처럼 너무 일반적인 표현만 있는 문장

## 5. 하드코딩 예시

아래는 엑셀 1차 분류에 바로 옮겨 넣기 쉬운 Python 형태의 기준이다.

```python
import re

TYPE_RULES = {
    "환불취소": [
        r"환불", r"취소", r"반품", r"교환",
        r"중복\s*결제|결제가\s*중복",
        r"실수로.*주문", r"마음이\s*바뀌",
        r"색상이.*사진과.*달라|사진과.*달라",
        r"사이즈가.*안\s*맞",
    ],
    "배송지연": [
        r"배송.*늦|늦.*배송", r"배송\s*지연",
        r"택배.*그대로|택배.*조회",
        r"아직.*도착\s*안|도착을?\s*안",
        r"언제쯤\s*오", r"일주일.*도착",
        r"택배\s*기사님.*방문.*못\s*받",
    ],
    "사용문의": [
        r"초기\s*설정", r"앱에서\s*설정", r"설정을\s*어떻게",
        r"사용법", r"사용\s*방법", r"매뉴얼",
        r"방법을\s*알려", r"사용\s*방법이\s*맞는지",
        r"작동이\s*잘\s*안.*방법",
    ],
    "제품하자": [
        r"불량", r"파손", r"고장", r"하자",
        r"전원이\s*안", r"작동하지\s*않",
        r"마감\s*부분", r"이음새", r"박스가\s*파손",
    ],
    "칭찬감사": [
        r"좋아", r"최고", r"만족스럽|만족도", r"감사",
        r"덕분에\s*잘\s*해결", r"친절하게\s*답",
        r"상담부터\s*응대까지",
    ],
}

TYPE_PRIORITY = ["환불취소", "배송지연", "사용문의", "제품하자", "칭찬감사"]

NEGATIVE_RULES = [
    r"짜증", r"최악", r"화가", r"실망", r"불편", r"별로",
    r"ㅠㅠ|😭", r"답변이\s*없", r"해결이\s*안", r"처리가\s*안", r"아쉬웠",
]

POSITIVE_RULES = [
    r"좋아", r"최고", r"만족", r"감사", r"다행", r"친절", r"덕분에\s*잘\s*해결",
]

RISK_RULES = [
    r"법적\s*대응|법적대응", r"변호사",
    r"소비자\s*보호원|소비자원", r"신고|고발",
    r"언론|제보", r"SNS.*확산|확산",
    r"화재|부상|감전|유해물질|다쳤|위험",
]

def has_any(text, patterns):
    return any(re.search(pattern, text) for pattern in patterns)

def match_labels(text, rules):
    return {
        label: [pattern for pattern in patterns if re.search(pattern, text)]
        for label, patterns in rules.items()
    }

def classify_type(text):
    matches = match_labels(text, TYPE_RULES)
    for label in TYPE_PRIORITY:
        if matches[label]:
            return label, matches
    return "기타", matches

def classify_sentiment(text):
    neg = has_any(text, NEGATIVE_RULES)
    pos = has_any(text, POSITIVE_RULES)
    if neg:
        return "부정"
    if pos:
        return "긍정"
    return "중립"

def classify_risk(text):
    return "Y" if has_any(text, RISK_RULES) else "N"

def needs_review(text, voc_type, matches, risk):
    matched_types = [label for label, patterns in matches.items() if patterns]
    if risk == "Y":
        return "Y"
    if voc_type == "기타":
        return "Y"
    if len([label for label in matched_types if label != "칭찬감사"]) >= 2:
        return "Y"
    if "제품하자" in matched_types and "사용문의" in matched_types:
        return "Y"
    if has_any(text, NEGATIVE_RULES) and has_any(text, POSITIVE_RULES):
        return "Y"
    return "N"
```

## 6. 권장 작업 순서

1. 위 규칙으로 `문의유형_1차`, `감정_1차`, `위험대응`, `검토필요` 컬럼을 만든다.
2. `위험대응=Y`는 사람이 반드시 본다.
3. `검토필요=Y`만 2차 검토한다.
4. 검토 결과로 누락/오분류 키워드를 추가한다.
5. 최종 컬럼은 `문의유형`, `감정`, `위험대응`으로 확정한다.
