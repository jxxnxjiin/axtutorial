# VOC 분류표 검산 결과

대조 대상: `1. VOC원문.xlsx`(520건) ↔ `3. 분류표.xlsx`(520건) ↔ `2. VOC_분류기준.pdf`

전체 520건 item_id가 두 파일에서 1:1로 일치함(누락·중복 없음). 채널(전화상담/메일/게시판/SNS) 값도 원문과 100% 일치.

---

## 1. 문의유형·감성 값 범위 검사

- 문의유형(6종: 환불취소·배송지연·제품하자·사용문의·칭찬감사·기타) 밖의 값 또는 빈칸: **0건**
- 감성(3종: 긍정·부정·중립) 밖의 값 또는 빈칸: **0건**

→ 이상 없음. 어긋난 item_id 없음.

## 2. 긍정·중립 감성 + 신고/소송/안전 신호 문장의 위험대응(Y) 확인

PDF 3장 기준(법적 대응 예고: 변호사·소비자원·고발·신고·소송·법적대응 / 여론 확산: 언론·제보·확산 / 안전 위험: 화재·부상·감전·유해·폭발 등) 키워드로 원문 520건을 전수 스캔.

- 키워드 매칭 총 68건 → 분류표상 위험대응=Y 총 68건 → **완전히 일치**(누락 0건, 과다 표시 0건)
- 감성이 **긍정**인데 위험 신호가 섞여 있고 위험대응=Y로 정확히 표시된 사례 다수 확인 (예: L-021, L-103, L-132, L-148, L-245, L-251, L-269, L-317, L-363, L-367, L-399, L-450, L-490 등 "만족스럽게 잘 쓰고 있어요... 소비자원에 신고/변호사/언론 제보" 패턴) → PDF의 "긍정 문장 + 위험 신호" 함정 규칙이 정확히 반영됨
- 감성이 **중립**인데 위험대응=Y인 사례도 모두 확인됨 (배송지연·제품하자·사용문의·환불취소 문의에 "소비자원 신고/소송/언론 제보" 문구가 덧붙은 경우)

→ 이상 없음. 어긋난 item_id 없음.

## 3. '검토필요' 표시 26건 및 복합 문의 재대조

**검토필요 26건** (L-071, L-073, L-074, L-105, L-112, L-118, L-140, L-153, L-159, L-163, L-165, L-205, L-214, L-316, L-338, L-354, L-359, L-360, L-366, L-379, L-398, L-403, L-404, L-446, L-447, L-494)
→ 원문 대조 결과 전부 "질문 하나 드려도 될까요", "그냥 남겨보는 글이에요", "매장 위치 좀 알려주세요" 류의 정보 없는 인사말·확인 요청으로, PDF 6종 어디에도 명확히 해당하지 않음. 기준서 4장의 "확신 없는 건은 기타/중립 처리 후 검토필요 표시" 원칙에 부합. **오분류 없음.**

**복합 문의 우선순위 규칙 재검증:**
- "하자 언급 + 환불/교환/반품 요구" → 환불취소로 분류돼야 하는 문장 전수 검사: **위반 0건**
- "고장 같아요"(제품하자) vs "방법을 알려주세요"(사용문의) 구분 전수 검사: **위반 0건**
- "전원이 안 켜져요 + 고장인 것 같아요" → 제품하자 판정: **위반 0건**
- "불만 + 그래도 상담원은 친절했어요" 류 문장에서 칭찬이 부수 표현으로 처리(본 사안 유지)되는지 확인: **위반 0건**

→ 이상 없음. 어긋난 item_id 없음.

## 종합 결론

4개 항목 모두 **어긋난 item_id 없이 통과**. 다만 이 검산은 스크립트 기반 키워드/규칙 매칭으로 수행되었으므로, 특히 아래는 사람이 한 번 더 훑어보시길 권합니다.
- 위험 신호 키워드 목록(변호사·소비자원·고발·신고·언론·제보·확산·소송·법적대응·화재·부상·감전·유해·폭발 등)에 포함되지 않은 새로운 표현 방식의 위험 신호가 있을 가능성
- '검토필요' 26건은 유형 판정이 불가한 것이 맞는지 최종 확인(현재는 원문에 실제로 판단 근거가 없는 것으로 확인됨)
