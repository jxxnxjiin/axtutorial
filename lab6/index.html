여유 실습 B · 내 대시보드를 인터넷에 올려 링크로 공유하기¶

강의 중에는 하지 마세요

계정 가입과 설정에서 시간이 통째로 녹습니다. 그리고 실패하면 하루의 마지막 인상이 실패가 됩니다. 집에 가서, 여유 있을 때 하세요. 이 페이지는 그때 보라고 있는 페이지입니다.

🏃 혼자 완주하는 실습입니다. 예상 30분 이상

한 줄 목표: 실습 4에서 만든 화면을 링크 하나로 남에게 보여준다.

올리기 전에 — 반드시 읽으세요¶

인터넷에 올린다는 건 누구나 볼 수 있다는 뜻입니다

  • 강의 데이터는 전부 가상입니다. 회사도 사람도 계약도 지어낸 것이라 올려도 됩니다
  • 그런데 나중에 여러분 회사 자료나 개인정보로 같은 걸 하면, 그건 공개된 인터넷에 올리는 겁니다
  • 이름·연락처·계약금액·거래처명이 화면에 있다면 올리기 전에 지우세요
  • 회사 자료는 회사 규정을 먼저 확인하세요. 대부분의 회사는 외부 공개를 금지합니다

올리기 전에 화면을 한 번 훑으며 이 셋을 확인하세요.

  • 사람 이름이 화면에 없다 (또는 가상 이름이다)
  • 연락처·주소가 없다
  • 회사 내부에서만 아는 금액·거래처가 없다

올리는 방법 — 세 가지 중 하나¶

파일 하나짜리 화면이라 가장 간단한 방식으로도 됩니다.

방식 가입 필요 걸리는 시간
정적 호스팅 서비스에 폴더를 끌어다 놓기 있음 10분
코드 저장소의 페이지 기능 켜기 있음 20분
사내 공유 폴더에 두고 경로로 열기 없음 2분

세 번째는 인터넷에 올리는 게 아니라 회사 안에서만 여는 방식입니다. 대부분의 실무에서는 이게 정답입니다.

AI에게 시켜서 진행하기¶

여기도 여러분 문장으로 시작합니다.

여기에 여러분 말로 채워서 실행하세요

__________

(지금 폴더의 dashboard.html 을 링크로 열 수 있게 올리는 방법을, 가입부터 링크가 나오기까지 순서대로 알려달라고 하는 방향입니다)

이렇게 나오면 정상입니다

  • 순서가 번호로 나옵니다
  • 각 단계에서 화면에 뭐가 보이면 통과인지가 적혀 있습니다
  • 마지막에 https:// 로 시작하는 주소가 나옵니다

이렇게 나왔다면

  • 설명이 너무 어렵다 → "컴퓨터를 잘 모르는 사람에게 설명하듯이, 클릭할 버튼 이름까지 적어서 다시 알려줘"
  • 중간에 명령어가 잔뜩 나온다 → "명령어 말고 화면에서 마우스로 하는 방법으로 알려줘"
  • 주소를 열었더니 빈 화면이다 → "올린 주소를 열었더니 빈 화면이야. 뭘 확인해야 하는지 순서대로 알려줘"

캡처를 남기세요¶

가입부터 링크가 나오기까지 화면을 몇 장 캡처해두면, 다음에 할 때 훨씬 빠릅니다.

내리는 방법¶

올리는 것만큼 내리는 방법을 아는 게 중요합니다.

여러분 말로 시켜보세요

__________

(올린 것을 내리는 방법과, 내려간 걸 어떻게 확인하는지 물어보는 방향입니다)

이렇게 나오면 정상입니다

  • 주소를 다시 열었을 때 화면이 안 열립니다
  • 브라우저 기록을 지우고 다시 열어도 안 열립니다

이렇게 나왔다면

  • 아직 열린다 → 브라우저가 저장해둔 화면일 수 있습니다. 다른 브라우저의 시크릿 창에서 다시 확인하세요

체크포인트

  • 올리기 전에 화면에 개인정보가 없는지 확인했다
  • 링크가 나왔고, 다른 기기에서 열어봤다
  • 내리는 방법을 확인했다
