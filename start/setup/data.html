5 · 실습 데이터 준비¶

이 페이지에서 하는 일

  • 실습 데이터 전체 zip을 내려받습니다
  • 경로 문제가 안 생기는 올바른 위치에 압축을 풉니다

도구 설치가 끝났으니, 오늘 만질 실습 재료를 내려받아 압축까지 풀어둡니다.

1. 전체 zip 내려받기¶

홈 화면의 내려받기 표에서 전체 zip을 받습니다.

2. 올바른 위치에 압축 풀기¶

압축을 풀 위치가 중요합니다.

바탕화면에 풀지 마세요

경로에 한글이나 띄어쓰기가 섞이면 도구가 파일을 못 찾는 일이 실제로 생깁니다. 윈도우: C:\workshop\ / 맥: ~/workshop/에 푸세요. 폴더가 없으면 직접 만드세요.

이렇게 나오면 정상입니다

  • workshop 폴더 안에 lab1 lab2 lab3 lab4 lab5 lab6 lab7 일곱 폴더가 보입니다
  • lab1 폴더를 열면 웹주문.xlsx, 전화주문.xlsx, 제휴주문.xlsx, 작업방법참고.xlsx, 주문종합.xlsx가 보입니다

이렇게 보인다면

  • 폴더 안에 같은 이름 폴더가 또 있다 → 안쪽 폴더가 진짜입니다. 안쪽 것을 workshop 아래로 옮기세요
  • 한글 이름이 깨진다 → 다른 압축 프로그램(반디집·알집 등)으로 다시 푸세요

다 됐는지 스스로 확인하기¶

  • C:\workshop\ (맥은 ~/workshop/) 안에 lab1~lab7 폴더가 있다
  • lab1 폴더를 열면 실습 파일들이 보인다

여기까지 됐으면 세팅과 데이터 준비가 모두 끝났습니다.
