0. 준비물과 사전 설치¶

이 페이지에서 하는 일 (전날 밤, 약 30분)

  • 노트북에 도구 네 가지를 설치하고 로그인까지 끝냅니다
  • 파일을 고칠 때마다 뜨는 확인 창을 미리 꺼둡니다
  • 실습 데이터를 미리 내려받아 압축까지 풀어둡니다

이 페이지는 강의 전날까지 각자 끝내는 페이지입니다. 당일 강의실에서는 설치하지 않고 확인만 합니다. 40명이 동시에 내려받으면 강의실 인터넷으로는 감당이 안 됩니다.

다 설치돼 있으면 5분, 처음이면 30분 걸립니다. 전날 밤에 하세요.

1. 설치할 것 네 가지¶

# 무엇 어디서 다 됐는지 확인하는 법
1 VS Code — 파일을 열고 편집하는 프로그램 code.visualstudio.com 프로그램이 실행되면 통과
2 Node.js (LTS 버전) nodejs.org 아래 2번 항목 참고
3 Python 3.10 이상 python.org 아래 2번 항목 참고
4 Claude Code — 오늘 말을 걸 상대 아래 3번 항목 참고 아래 3번 항목 참고

윈도우에서 Python을 설치할 때

설치 첫 화면 아래쪽의 Add Python to PATH 체크박스를 반드시 켜세요. 이걸 놓치면 4번에서 막힙니다. 이미 설치했는데 안 켰다면, 설치 파일을 다시 실행해 Modify로 고칠 수 있습니다.

2. 터미널에서 세 줄 확인하기¶

터미널은 명령을 글자로 입력하는 까만 화면입니다. VS Code 안에서 열 수 있습니다.

  1. VS Code를 실행합니다
  2. 위 메뉴에서 터미널 > 새 터미널 (단축키 Ctrl+</kbd>, 맥은 <kbd>Cmd</kbd>+<kbd>)
  3. 아래쪽에 뜬 까만 창에 아래 세 줄을 한 줄씩 입력하고 Enter
node -v
python --version
claude --version

이렇게 나오면 정상입니다

  • node -v → v20. 으로 시작하는 숫자가 나옵니다
  • python --version → Python 3.10 이상 숫자가 나옵니다 (맥은 python3 --version)
  • claude --version → 숫자가 나옵니다

이렇게 나왔다면

  • 명령을 찾을 수 없습니다 / command not found → 설치는 됐는데 터미널이 아직 모르는 상태입니다. VS Code를 완전히 껐다가 다시 켜고 같은 줄을 다시 입력하세요
  • 그래도 같은 메시지 → 그 도구가 설치되지 않은 것입니다. 위 표의 링크에서 다시 설치하세요
  • 윈도우에서 python이 앱스토어를 열어버린다 → Add Python to PATH를 켜지 않고 설치한 경우입니다. 설치 파일을 다시 실행해 고치세요

3. Claude Code 설치와 로그인¶

터미널에 아래 한 줄을 입력합니다.

npm install -g @anthropic-ai/claude-code

설치가 끝나면 터미널에 claude를 입력하고 Enter. 처음이면 로그인 화면이 뜹니다. 안내대로 브라우저에서 로그인하세요.

이렇게 나오면 정상입니다

claude를 입력했을 때 로그인 화면 없이 바로 입력줄이 뜹니다

이렇게 나왔다면

  • 로그인 화면에서 더 진행이 안 된다 → 계정 문제입니다. 운영진에게 연락하세요. 당일 예비 계정을 받을 수 있습니다
  • 설치 명령에서 권한 오류가 난다 → 맥/리눅스는 명령 앞에 sudo를 붙여 다시 시도하세요

4. 확인 창 미리 꺼두기 (자동 승인)¶

AI가 파일을 고칠 때마다 "이 파일을 수정해도 될까요?" 하고 물어봅니다. 오늘 하루는 파일을 수백 번 고치므로, 미리 꺼둡니다.

VS Code 오른쪽 Claude Code 패널 하단의 모드 드롭다운에서 Edit automatically를 고릅니다.

모드 동작
Ask before edits 고칠 때마다 물어봅니다 (기본값)
Edit automatically 파일 편집은 자동, 터미널 명령은 여전히 확인 — 오늘 이걸 고르세요
Plan mode 고치기 전에 계획을 먼저 보여줍니다

고르고 나면 입력창 오른쪽 아래에 Edit automatically 라벨이 뜹니다.

터미널 명령까지 자동으로 넘기고 싶다면 (선택)

실습 4에서 화면을 여러 번 다시 만들 때 조금 더 편합니다. 다만 켜지 않아도 오늘 실습은 전부 진행됩니다.

1단계. VS Code 왼쪽 아래 톱니바퀴 → Settings (Ctrl+,)

2단계. 왼쪽 트리에서 Extensions → Claude Code

3단계. 맨 위 Allow Dangerously Skip Permissions 체크박스를 켭니다

4단계. Claude Code 패널 하단 드롭다운에서 Bypass permissions 선택

이 설정은 승인 없이 명령을 실행하게 합니다. 오늘 쓰는 실습 폴더에서만 쓰고, 회사 자료나 개인 파일이 있는 폴더에서는 켜지 마세요.

강의가 끝난 뒤 되돌리는 법
되돌릴 것 방법
자동 편집 모드 드롭다운에서 Ask before edits 로 되돌립니다
명령 자동 실행 Settings → Extensions → Claude Code → Allow Dangerously Skip Permissions 체크 해제

평소 작업 폴더에서는 되돌려 쓰시길 권합니다. 실수로 지운 파일을 되살릴 방법이 없는 경우가 있습니다.

5. 디자인 스킬 미리 받아두기 (실습 4에서 씁니다)¶

실습 4에서 화면 인상을 한 줄로 갈아입히는 데 씁니다. 터미널에 아래를 입력해 설치합니다.

claude plugin marketplace add anthropics/skills

설치되면 claude 안에서 /minimalist-ui 라고 입력했을 때 목록에 뜹니다.

이렇게 나오면 정상입니다

claude 실행 후 /min 까지만 쳐도 /minimalist-ui 가 후보로 보입니다

안 떠도 실습은 진행됩니다

실습 4 데이터 폴더에 디자인_지시문/ 이라는 대체 파일 3장이 들어 있습니다. 스킬 대신 그 파일을 읽히면 결과가 거의 같습니다. 자세한 방법은 실습 4 · 5단계에 있습니다.

6. 데이터 내려받고 압축 풀기¶

홈 화면의 내려받기 표에서 전체 zip을 받습니다.

압축을 풀 위치가 중요합니다.

바탕화면에 풀지 마세요

경로에 한글이나 띄어쓰기가 섞이면 도구가 파일을 못 찾는 일이 실제로 생깁니다. 윈도우: C:\workshop\ / 맥: ~/workshop/ 에 푸세요. 폴더가 없으면 직접 만드세요.

이렇게 나오면 정상입니다

  • workshop 폴더 안에 lab1 lab2 lab3 lab4 lab5 다섯 폴더가 보입니다
  • lab1 폴더를 열면 발송내역.xlsx, 청구서_A택배.csv, 요금안내문 폴더가 보입니다

이렇게 보인다면

  • 폴더 안에 같은 이름 폴더가 또 있다 → 안쪽 폴더가 진짜입니다. 안쪽 것을 workshop 아래로 옮기세요
  • 한글 이름이 깨진다 → 다른 압축 프로그램(반디집·알집 등)으로 다시 푸세요

다 됐는지 스스로 확인하기¶

  • node -v · python --version · claude --version 세 줄이 전부 숫자를 답한다
  • claude 를 입력하면 로그인 화면 없이 입력줄이 뜬다
  • Claude Code 패널 아래에 Edit automatically 라벨이 보인다
  • C:\workshop\ (맥은 ~/workshop/) 안에 lab1~lab5 폴더가 있다

여기까지 됐으면 전날 준비 끝입니다. 당일에는 처음 5분부터 시작합니다.
