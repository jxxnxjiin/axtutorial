1. 처음 5분 — 폴더 열고 말 걸기¶

이 단계에서 하는 일 (약 5분)

  • 실습 폴더를 VS Code로 엽니다
  • 폴더 아래쪽에서 터미널(까만 화면)을 엽니다
  • 첫 문장을 걸어보고, 답이 오는 걸 확인합니다

여기는 전원이 통과해야 다음으로 넘어가는 자리입니다. 어려운 건 없습니다. 화면 네 개가 순서대로 보이면 통과입니다.

① 폴더 열기¶

VS Code를 실행하고, 위 메뉴에서 파일 > 폴더 열기 를 눌러 압축을 푼 workshop 폴더를 고릅니다.

파일 열기가 아니라 폴더 열기입니다

가장 흔한 실수입니다. 파일 하나만 열면 AI가 옆에 있는 다른 파일들을 보지 못합니다.

이렇게 나오면 정상입니다

왼쪽 목록에 lab1 lab2 lab3 lab4 lab5 다섯 폴더가 보입니다

이렇게 나왔다면

  • 왼쪽에 파일 하나만 보인다 → 파일 > 폴더 열기로 다시 하세요
  • 폴더가 안 보인다 → 압축을 푼 위치를 다시 확인하세요. C:\workshop\ 또는 ~/workshop/ 입니다

② 터미널 열기¶

Ctrl+</kbd> (맥은 <kbd>Cmd</kbd>+<kbd>) 를 누릅니다. 위 메뉴의 터미널 > 새 터미널 도 같습니다.

이렇게 나오면 정상입니다

아래쪽에 까만 창이 뜨고, 그 안에 적힌 경로가 workshop으로 끝납니다

이렇게 나왔다면

  • 경로 끝이 workshop이 아니다 → ①에서 다른 폴더를 열었습니다. 파일 > 폴더 열기로 다시
  • 까만 창이 안 보인다 → 위 메뉴 보기 > 터미널

③ 말 걸기¶

까만 창에 claude 를 입력하고 Enter. 입력줄이 뜨면 아무 말이나 걸어봅니다.

여러분 말로 한 줄만 걸어보세요

(예: 지금 열려 있는 폴더 이름이 뭐야?)

여기에 정답은 없습니다. 말이 통한다는 것만 확인하는 자리입니다.

이렇게 나오면 정상입니다

폴더 이름을 맞게 답합니다

이렇게 나왔다면

  • 로그인 화면이 뜬다 → 조교를 부르세요. 예비 계정이 있습니다
  • command not found → VS Code를 완전히 껐다 켠 뒤 다시 시도하세요

④ 첫 성공 미션¶

아래 한 줄을 그대로 복사해 넣으세요. 오늘 하루 중 완성 문장을 그대로 복사하는 몇 안 되는 자리입니다.

이 폴더 안에 어떤 파일이 몇 개 있는지 표로 정리해서 알려줘.

이렇게 나오면 정상입니다

폴더별 파일 개수가 적힌 표가 화면에 나옵니다. lab1 안에 파일과 폴더가 여러 개 있다고 답합니다

이렇게 나왔다면

  • "폴더가 비어 있다"고 한다 → 열려 있는 폴더가 workshop이 아닙니다. ①로 돌아가세요
  • 한참 답이 없다 → 1분 정도는 정상입니다. 3분이 지나도 답이 없으면 Ctrl+C 로 멈추고 다시 시도하세요

뭐가 달라졌는지 봅니다 — 체크포인트

  • 왼쪽에 lab1~lab5 다섯 폴더가 보인다
  • 터미널 경로 끝이 workshop 이다
  • AI가 폴더 이름을 맞게 답했다
  • 파일 개수 표가 화면에 나왔다

여기까지 됐으면 오후 실습을 시작할 수 있습니다.
