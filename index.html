##

오늘의 지도

6 types

오늘 익힐 건 결국 여섯 가지 작업이에요. 직무가 영업이든 인사든 마케팅이든, 손으로 반복하는 일은 아래 여섯 모양 중 하나의 조합입니다. 각 카드에 입력 → 출력과 오늘 그걸 만나는 실습을 붙였어요 — 여섯 유형 자세히 보기 →

TYPE ① · 추출·파싱
뽑기
비정형(PDF·이미지) → 표
구조 없던 걸 표로 만든다
실습계약서 한 장
TYPE ② · 취합·통합
모으기
정형 여러 개 → 정형 하나
행을 보존하며 여러 파일을 합친다
실습주문 한 표로원본 대조·검산
TYPE ③ · 집계·분석
줄이기
정형 표 → 요약·지표
행을 줄여 수치·인사이트로
실습쿠폰 성과 집계대시보드 지표
TYPE ④ · 분류
딱지 붙이기
자유 텍스트 → 범주 라벨
이게 뭐냐 (정답이 모호)
실습개념 위주 · 준비 중
TYPE ⑤ · 초안 작성
쓰기
자료 → 새 산문
없던 글을 쓴다
실습준비 중
TYPE ⑥ · 검증·검수
검사하기
데이터 + 규칙 → 위반 판정
규칙에 맞냐 (정답이 규칙)
실습주문 대조·검산집계 검산

materials/

#1주문 취합 · 계약서 뽑기 모으기뽑기

창구별로 흩어진 주문을 한 표로 모으고, 양식이 제각각인 계약서 PDF 8건에서 계약대장을 뽑습니다.

└─ 계약서 (contract) · 8건
pdfCT-2026-001↓ pdfCT-2026-002↓ pdfCT-2026-003↓ pdfCT-2026-004↓ pdfCT-2026-005↓ pdfCT-2026-006↓ pdfCT-2026-007↓ pdfCT-2026-008↓
02
#2채널별 주문 통합 · 집계 모으기줄이기

5개 채널에 흩어진 주문기록 9천여 건을 하나로 합쳐 쿠폰별 성과를 집계합니다.

⤓ #2 자료 zip 880KB xlsx1.주문기록_11번가.xlsx↓ xlsx2.주문기록_네이버.xlsx↓ xlsx3.주문기록_이마트.xlsx↓ xlsx4.주문기록_지마켓.xlsx↓ xlsx5.주문기록_쿠팡.xlsx↓ xlsx6.GA5_주문종합.xlsx↓ xlsx7.쿠폰별성과표.xlsx↓

##

실습 가이드

한 페이지 = 한 단계

단계별 상세 안내가 이 위키 안에 그대로 들어 있습니다. 한 페이지가 한 단계이니, 앞질러 가지 말고 지금 페이지 맨 아래 체크포인트를 먼저 통과하세요.

L1
실습 1 · 흩어진 주문 한 표로 모으기 ▷
웹·전화·제휴 세 파일을 표준 7칸으로 합치고, 빠지거나 겹친 건이 없는지 검산합니다.
 L2
실습 2 · 계약·입찰 레이더 ▷
계약서 PDF와 공고를 한 표로. 회사소개·SKILL.md까지.
 L3
실습 3 · 쿠폰 성과 집계·인사이트 ▷
주문 9천 건을 쿠폰별 성과표로 줄이고, 취소·평균 함정을 검산한 뒤 근거 있는 인사이트를 뽑습니다.
 L4
실습 4 · 대시보드 + 디자인 ▷
내 데이터가 도는 화면을 만들고 인상을 직접 고릅니다.
