직무가 영업이든 인사든 마케팅이든, 손으로 반복하는 일은 아래 여섯 모양 중 하나예요. 오늘 실습은 이 여섯을 실제 데이터로 하나씩 손에 익히는 시간입니다.

유형별로 뜯어보기 · 연결 실습

각 유형이 왜 헷갈리는지와, 오늘 그걸 어느 실습에서 만나는지를 함께 붙였어요.

①뽑기추출·파싱
비정형(PDF·이미지) → 표
비유
받아쓰기 — 불러주는 걸 칸에 옮겨 적기
실무
계약서 PDF에서 기한·금액 뽑기 · 영수증 사진을 표로
함정
없는 값을 그럴듯하게 지어냄 → "안 적힌 건 0이 아니라 빈칸, 지어내지 마"
실습1요금표를 표로실습2계약서 한 장
②모으기취합·통합
정형 여러 개 → 정형 하나
비유
빨래를 한 바구니에 — 단, 한 짝도 안 빠뜨린다
실무
웹·전화·제휴 주문을 한 대장으로 · 업체별 견적을 비교표 한 장으로
함정
합계까지 내버림(=③ 줄이기와 혼동) · 빈칸을 0으로 채움
실습1청구서 합치기실습2열두 건으로
③줄이기집계·분석
정형 표 → 요약·지표
비유
한 달치 영수증을 "이번 달 총 얼마" 한 줄로
실무
9천 줄 주문 로그 → 쿠폰별 ROI · 일별 매출 → 사원별 실적
함정

④딱지 붙이기분류
자유 텍스트 → 범주 라벨
비유
빨래를 색깔별로 — 단, 느낌 말고 규칙대로
실무

⑤쓰기초안 작성
자료 → 새 산문
비유
