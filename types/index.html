여섯 가지 업무 유형¶

직무가 영업이든 인사든 마케팅이든, 손으로 반복하는 일은 아래 여섯 모양 중 하나의 조합이에요. 각 유형이 무엇을 무엇으로 바꾸는지와, 직무별로 실무에서 어떤 상황과 만나는지를 정리했습니다. 구체적인 처리법·함정·검산은 연결된 실습에서 직접 다룹니다.

한눈에 보는 6유형¶

코드쉬운 이름입력 → 출력한 줄 판별
①뽑기추출·파싱비정형(PDF·이미지) → 표"구조 없던 걸 표로 만든다"
②모으기취합·통합정형 여러 개 → 정형 하나"행을 보존하며 여러 파일을 합친다"
③줄이기집계·분석정형 표 → 요약·지표"행을 줄여 수치·인사이트로"
④딱지 붙이기분류자유 텍스트 → 범주 라벨"이게 뭐냐 (정답이 모호)"
⑤쓰기초안 작성자료 → 새 산문"없던 글을 쓴다"
⑥검사하기검증·검수데이터 + 규칙 → 위반 판정"규칙에 맞냐 (정답이 규칙)"

직무별로 만나는 실무 상황¶

같은 유형이라도 직무마다 다른 얼굴로 나타나요. 아래는 각 유형이 실무에서 만나는 대표 상황들 — 구체적인 처리법은 연결된 실습에서 다룹니다.

①뽑기추출·파싱
비정형(PDF·이미지) → 표
총무·법무
계약서 PDF 더미에서 계약번호·기한·금액·자동갱신 여부 → 계약대장
회계
영수증 사진에서 가맹점·금액·항목을 표로 (OCR)
마케팅
경쟁사 화면 캡처에서 가격·구성요소를 표로 (벤치마킹)
②모으기취합·통합
정형 여러 개 → 정형 하나
영업지원
웹·전화·제휴 주문 파일을 한 주문대장으로
구매
업체별 견적서 여러 개를 비교표 한 장으로
HR·운영
지점별·부서별 매출/문의 표를 본사 한 표로
③줄이기집계·분석
정형 표 → 요약·지표
마케팅
9천 줄 주문 로그 → 쿠폰별 ROI · 발송로그 → 캠페인별 오픈·클릭·전환율
영업
일별 매출 → 사원별·월별 실적·목표대비
HR
설문 500건 → 항목별 응답률 · 근태 로그 → 월별 집계
④딱지 붙이기분류
자유 텍스트 → 범주 라벨
CS·운영
고객 문의를 문의유형·감성·위험으로 분류하고 담당 부서로 라우팅
HR
들어온 이력서에 "서류 통과·보류" 1차 태그
회계
영수증·카드내역을 계정과목으로 분류
⑤쓰기초안 작성
자료 → 새 산문
마케팅
제품 정보 시트 → 상세설명·홍보 카피 초안
HR·총무
명단 → 수료증·재직증명서 100장 일괄 생성 (mail-merge)
공통
집계 결과 → 주간 보고 초안
⑥검사하기검증·검수
데이터 + 규칙 → 위반 판정
재경·회계
발주·입고·세금계산서 3장부 대사 · 은행 거래내역 vs 장부
물류·총무
창고 실사 vs 전산 재고 · 자산 명부 정합성
데이터·마케팅
메타데이터가 규칙(길이·중복·누락)에 맞는지 감사
